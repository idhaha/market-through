# 2026-10-23 Rank 차트 작업 기록

기준: 한국 시간 2026-10-23. 오늘 대화에서 변경한 로컬 구현과 검증을 정리한다. 현재 동작의 상세 기준은 [공통 차트 정책](../RANK_CHART_POLICY.md)이다. 중간에 취소·대체한 정책을 최종 정책으로 적용하지 않는다.

## 출처와 조작 버튼

- 카드 하단 오른쪽에 출처를 표시한다. 쏠림율·수급·신고가/신저가·거래대금은 키움, ADR·변동성·CNN/하이일드는 jusikbot이다. 대주가능 종목 카드는 한투다.
- 신고가/신저가의 현재 원천은 키움 `ka10016`이다. 이전 jusikbot 자료의 보존·이관 이력과 현재 수집 원천을 구분하도록 문서를 정정했다.
- 기간 선택 버튼을 제거하고 기본 조작을 `일 / 1분봉 / 당일 / 더 불러오기 / 캔들차트`로 맞췄다. 변동성·CNN에는 분봉과 당일 버튼을 만들지 않는다. 쏠림율의 분 간격은 1분으로 통일했다.

## 초기 조회와 표시 기간

- 초기 일봉은 최초 기준 가격 캔들 조회 응답의 실제 봉 수·시간축을 사용한다. 고정 600봉이나 임의 달력 기간을 강제하지 않는다. 변동성·CNN·ADR도 지표 관측 개수가 아닌 기준 캔들로 축을 잡는다.
- 처음 분봉 선택 및 당일 버튼은 한국 시간 당일 08:00부터 표시한다. 지수나 지표가 09:00부터 있으면 앞 구간은 비워둔다. 오늘 자료가 없다고 이전 거래일을 오늘처럼 표시하지 않는다.
- 누락 지표·가격을 0, 직전 값 또는 보간으로 만들지 않는다. 지표가 없어도 실제 가격 캔들이 있으면 유지한다.
- 분봉 표시 기간은 공통 시작 시각과 참여 차트의 최신 수신 시각을 기준으로 한다. 차트별 첫 관측 시각 때문에 축이 줄어들지 않도록 했다.

## 전체 동기화

- 어느 차트에서 일봉을 선택해도 전체가 일봉으로 전환된다. 분봉을 선택하면 지원하는 5개 차트가 전환되고 변동성·CNN은 일봉을 유지한다.
- 어느 차트에서 더 불러오기를 눌러도 현재 같은 주기의 모든 차트가 추가조회에 참여한다. 원천별 페이지·cursor 방식은 유지한다.
- 확보한 최초 날짜/시각 중 가장 최신 값을 공통 시작점으로 사용한다. 더 오래 확보된 원본 자료를 삭제하지 않는다. 반복 추가조회에도 같은 원칙을 적용한다.
- 추가조회 동안 기존 공통 시작점을 유지하고 전체 완료 후 범위를 갱신한다. 더 과거로 확장할 자료가 없어도 모든 참여 차트를 같은 범위로 다시 맞춘다. 첫 추가조회가 당일 08:00을 09:00으로 좁히지 않도록 했다.
- 일봉 최초 진입은 각 기준 캔들 첫 조회 정책이며, 일봉 추가조회 또는 확대·스크롤 조작 이후 공통 날짜 범위를 사용한다.
- 확대·축소 버튼, 휠, 드래그 확대 및 하단 슬라이더는 봉 인덱스 대신 실제 시작·종료 날짜/시간을 공유한다. 자료가 드문 차트도 같은 기간을 표시하고 없는 부분은 비운다. 일봉과 분봉 범위는 분리한다.
- 단순 클릭·호버는 확대 범위를 바꾸지 않는다. 주기 전환·당일·추가조회는 해당 공통 범위 정책으로 재설정한다.
- 메인창의 캔들 펼침은 7개 차트에 함께 적용한다. 새로고침 복원도 쏠림율의 저장된 공통 펼침 상태를 따른다. 늦게 초기화되는 수급이 개별 설정으로 이를 덮어쓰지 않게 했다. 독립창의 캔들 펼침은 창별 정책을 유지한다.

## 공통 X축과 캔들

- 공통 모듈 `public/rank-chart-axis.js`를 메인창·독립창의 차트보다 먼저 로드한다.
- 날짜 형식은 일봉 `YY-MM-DD`, 당일 분봉 `HH:mm`, 여러 거래일 분봉 `MM-DD HH:mm`이다. 실제 글자 폭·좌우 경계·최소 간격으로 겹침과 잘림을 방지한다.
- 동기화된 일봉은 공통 거래일 목록에서 최대 5개의 눈금 날짜를 선택한다. ADR 등 가격축 여백 차이로 드래그 후 눈금 날짜가 달라지는 문제를 수정했다. 본체와 아래 캔들은 같은 눈금을 사용한다.
- 모든 차트의 일봉·분봉에 공통 캔들 계산을 적용한다. 몸통은 실제 봉 간격의 70%, 최대 8px, 꼬리는 1px다. 양봉·보합은 빨강, 음봉은 파랑이다. 가격 고저 범위에 10% 여백(최소 1)을 두고 최솟값은 0 이상으로 제한한다.
- 쏠림율의 08~09시 실제 통합시장 가격을 서버에서 보존한다. 쏠림율 계산이 불가능하다고 OHLC와 시간축까지 제거하던 경로를 수정했다. 다른 종목·시장 자체의 가격 차이는 유지한다.

## 조회 순서와 표시 시점

- 시작 우선순위: 쏠림율 → 수급 → 신고가/신저가 → 거래대금 → ADR → CNN/하이일드 → 변동성.
- 일반 조회·자동 갱신·메인 새로고침은 위 순서로 비동기 요청을 시작하며 앞 차트의 완료를 기다리지 않는다. 완료된 차트부터 표시한다.
- 메인 초기화에서 개별 차트가 먼저 중복 조회하던 경로를 공통 갱신으로 통합했다. 선택 종목이 있으면 순위표 완료를 기다리지 않는다. 최초 종목이 없을 때만 순위 결과로 종목을 결정한 후 시작한다.
- 더 불러오기는 같은 우선순위로 순차 실행한다. 각 완료 자료는 바로 그리고 전체 완료 후 공통 범위를 확정한다. 일반 갱신의 병렬 시작과 구분한다.

## 하단 줄과 ADR 레이아웃

- 조회 기간·로딩·상태 메시지는 출처와 같은 하단 줄의 왼쪽, 출처는 오른쪽에 둔다. 긴 문구는 한 줄 말줄임 처리한다.
- 확보한 26px를 본체에 돌려주어 메인 플롯을 260px에서 286px로 늘렸다.
- ADR은 상태 문구를 기준으로 캔들과 슬라이더를 삽입하고 있어, 상태를 하단 줄로 옮기자 두 영역도 메시지 컨테이너에 들어갔다. 삽입 기준을 본체와 캔들 영역으로 바꾸어 전체 폭과 세로 배치를 복구했다.

## API와 오류 수정

- `chart-reference-service.js`와 `/api/chart-reference`를 추가했다. 키움 시장지수 일봉·분봉 실제 첫 페이지와 연속조회 키를 제공하며 60초 메모리 캐시를 사용한다.
- `turnover-service.js`와 `/api/turnover/chart`를 추가했다. 시장별 거래대금 시계열과 과거 조회를 제공한다. 분봉 거래대금은 지수×거래량 기반 누적 추정값이며 거래일을 넘어 누적하지 않는다.
- 새 API가 등록되지 않은 실행 중 서버에서 HTML 홈페이지가 반환되어 JSON 파싱 오류가 발생하는 원인을 확인했다. 미등록 API는 JSON 404로 반환하고, 기준 API가 HTML이면 화면에 서버 반영·재시작 필요 상태를 표시하며 실제 지표 자료를 유지한다.
- 실제 키움 조회에서 종목과 지수의 1분봉 첫 페이지가 모두 900봉이면서 시작 날짜는 달랐다. 거래시간 차이가 있으므로 봉 수가 같아도 기간은 같지 않다. “ADR 분봉은 600봉”이라는 설명은 정정했으며 이 관측을 고정 개수 보장으로 해석하지 않는다.
- 최초 빈 응답의 0봉 상태가 뒤늦게 도착한 실제 분봉을 가리던 문제와, 과거 추가조회가 공통 범위를 당일 09:00으로 좁히던 문제를 수정했다.

## 적용 상태

- 이 기록의 범위는 로컬 작업 트리다. 커밋·원격 푸시·운영 배포는 수행하지 않았다.
- 화면 JS/CSS 변경은 새로고침으로 적용한다. 서버 서비스·라우트 변경은 해당 파일 반영과 Node 프로세스 재시작이 필요하다. 오늘 로컬 서버는 서버 변경을 적용하기 위해 재시작했다.
- 주요 구현은 공통 축, 5개 차트 스크립트, 갱신 조정 `public/app.js`, 출처·하단 줄 `public/rank-connection-status.js`, 화면 HTML/CSS 및 위 서버 서비스에 있다.

## 후속 변경: 독립창과 메인창의 차트 상태 분리

- 메인 상태 스냅샷을 독립창 차트에 계속 적용하던 경로와, 독립창 조회가 메인 차트의 종목·주기를 바꾸던 경로를 제거했다. 처음 창을 열 때의 종목 초기값만 복사한다.
- 독립창의 데이터 조회·자동 갱신은 자신의 선택과 주기를 사용한다. 메인의 인증 릴레이는 계속 사용한다.
- 독립창 내부의 쏠림율·수급 공통 주기·과거 조회·줌·스크롤은 유지한다. 메인창이나 다른 독립창의 축 상태에는 영향을 주지 않는다.
- 새 두 창 회귀 검증은 `dev/tests/rank-independent-isolation.test.cjs`다. 차트 표시 분리는 프런트 변경이므로 독립창을 닫고 다시 열어 최신 스크립트를 적용한다.

## 후속 수정: 드래그 선택 영역이 오른쪽 끝보다 먼저 멈추는 문제

쏠림율에 남아 있던 추가 24px 차감을 제거해 드래그 선택 영역과 공통 X축 끝점을 맞췄다. 실제 줌 계산·휠·호버도 같은 경계를 사용한다. `rank-drag-edge.test.cjs`에서 독립 모드 쏠림율·ADR의 본체 및 캔들 드래그 미리보기와 최신 분봉 포함을 확인했다.

## 후속 수정: 같은 분봉 시간대를 보는 줌 바의 위치 차이

차트별 봉 인덱스로 계산하던 줌 바를 공통 시간 범위의 상대 위치로 변경했다. 과거 페이지 수와 누락 구간이 달라도 같은 표시 기간이면 손잡이 위치가 같다. 이동도 공통 시간 좌표로 처리하며 당일 08:00 빈 구간을 유지한다. 공통 축 단위 검증 14개와 메인·독립 모드의 실제 브라우저 줌 바 이동 검증을 통과했다.

## 독립창 목록 단계 순서 변경

거래대금 목록 단계는 기본 → 중간(10개) → 최소(5개) → 기본으로 순환한다. 버튼의 현재·다음 단계 안내도 같은 순서로 변경했다. 기존 카드 높이 복원·창 너비 유지·갱신 시 표시 개수 유지 처리는 그대로 사용한다.
