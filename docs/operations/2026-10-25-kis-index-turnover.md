2026-10-25 한국시간 조사. 기존 EFRIEND 설정으로 시세 조회만 실행했다. 서비스 계산 및 UI는 변경하지 않았다.

- 분봉 TR FHKUP03500200의 output2.acml_tr_pbmn은 실제 응답에서 일중 누적값이다. 각 행을 합산하면 안 된다.
- 2026-10-08 코스피: 일봉 FHKUP03500100의 24,376,305와 시간봉 응답의 시간값 999999의 24,376,305가 정확히 같다. 첨부 키움 HTS의 24,376,305백만원과도 같다. 이 비교에서 한투 값은 백만원 스케일로 확인된다.
- 3600초·과거포함 Y·기타구분 0 조회는 102행을 반환했다. 2026-10-07~23의 12거래일에 최종 특수행이 존재하며, 코스피·코스닥 24건 모두 일봉과 정확히 같다. 10월 7일은 장중 행 일부만 있으므로 그날 전체 시간봉이 확보됐다는 의미는 아니다.
- 일봉 FHKUP03500100과 대체 일별 TR FHPUP02120000은 2026-10-01~23의 15거래일, 두 시장 총 30건 모두 거래대금이 같다.
- 최신 거래일 10월 23일 300초 조회에서는 FHKUP03500200과 FHPUP02110200의 81개 시간별 누적 거래대금이 두 시장 모두 전부 같다.

## 10월 23일 장중과 최종값 비교

다음 금액은 API 원본 숫자다. 10월 8일 첨부 HTS와의 비교에서 백만원 스케일을 확인했다.

코스피:
- 15:30:00 누적 16,474,192
- 특수 시간값 888888 누적 16,474,195
- 특수 시간값 999999 누적 17,374,311
- 일봉 17,374,311
- 15:30 누적과 일봉 차이 900,119, 일봉 대비 5.180746%

코스닥:
- 15:30:00 누적 5,488,463
- 특수 시간값 888888 누적 5,488,465
- 특수 시간값 999999 누적 5,807,985
- 일봉 5,807,985
- 15:30 누적과 일봉 차이 319,522, 일봉 대비 5.501426%

기타구분 1은 특수 시간값 888888, 999999를 제외했다. 일반 5분봉 행은 기타구분 0에도 존재한다. output1의 전체 누적값은 기타구분 1에서도 일봉과 같은 전체 누적값이었다. 따라서 output1을 정규장 누적값으로 사용하면 안 된다.

특수 시간값은 정상 HHMMSS가 아니다. 확인한 공식 샘플에는 각 값의 정확한 세션 정의가 없어 888888/999999를 특정 시간외 세션으로 단정하지 않는다. 관측상 999999가 일봉 최종 집계와 일치한다. 이를 15:30 봉에 합치면 실제 장중 배분을 왜곡한다.

## 쏠림율 계산에 미치는 영향

concentration-chart.js:86은 분봉 시장 분모를 (업종지수 / 100) × (거래량 × 10000)으로 계산한다. 일봉은 trde_prica 원본 거래대금이다. 분봉과 일봉의 분모 정의가 다르다. 업종지수는 체결 주가가 아니므로 해당 곱은 실제 시장 거래대금이 아니다.

분봉 분모를 실제 거래대금으로 바꾸려면 한투의 동일 날짜·업종 누적 거래대금을 시간순으로 차분한다. 첫 구간은 당일 누적 기준 0에서 계산하되, 첫 확보 행이 장중이면 그 이전 전체 누적액을 해당 한 봉에 배정하지 않는다. 날짜 경계에서 누적값을 초기화한다. 시간 라벨이 봉 시작/종료 중 무엇을 뜻하는지 키움 봉과 추가로 정렬해야 한다.

종목 분자도 현재는 종가×거래량인 추정치다. 실제 거래대금 비중으로 전환하려면 분자 또한 실제 거래대금으로 맞춰야 한다. 키움 종목의 KRX/NXT 범위와 한투 업종 범위 일치도 별도 확인이 필요하다. 이번 측정은 두 종합시장 대상이며 모든 세부 업종을 검증한 것은 아니다.

10월 8일은 3600초 조회로 최종값을 확보했고, 해당 날짜 전체 5분봉은 확보하지 않았다. 따라서 10월 8일 09:00~15:30 실제 누적 거래대금과 첨부 추정값의 차이를 세션별로 완전히 분해하지는 않았다.
