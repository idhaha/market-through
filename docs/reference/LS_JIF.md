# LS JIF 장운영정보

확인: 2026-10-30. 공식 페이지의 JavaScript에서 사용하는 공개 상세 JSON 경로로 조회했다. 정적 검색 화면의 `업스트림 연결 실패`와 달리 아래 상세 요청은 정상 응답했다.

- 안내: https://openapi.ls-sec.co.kr/apiservice
- 상세: https://openapi.ls-sec.co.kr/guide/api/148z73fs-4n7x-0ot8-46t8-63jg7w181y21?type=rest&api=eddd61f7-d595-4370-b9c3-49c4c6178096
- 연결: `wss://openapi.ls-sec.co.kr:9443/websocket`
- 구독: `header: {token, tr_type: "3"}`, `body: {tr_cd: "JIF", tr_key: "0"}`.
- 수신: `body.jangubun`, `body.jstatus`. 이벤트 시각·당일 이력 조회는 이 명세에 없다.

## 구현에 사용하는 의미

다음 경보 코드는 장구분 `1`(코스피), `2`(코스닥)에만 적용한다. 다른 장구분에서 같은 숫자는 다른 뜻일 수 있다.

- 61 / 62 / 63: CB 1단계 발동 / 해제·호가접수 / 동시호가 종료.
- 68 / 70 / 71: CB 2단계 발동 / 해제·호가접수 / 동시호가 종료.
- 69: CB 3단계 발동·당일 종료.
- 64 / 65: 사이드카 매도 발동 / 해제.
- 66 / 67: 사이드카 매수 발동 / 해제.
- 00: 장상태 초기화. 21: 장 시작. 41: 장 마감.

69 자체를 일반 41 마감으로 처리해 새 3단계 경보를 즉시 숨기지 않는다. 장구분별 41·00 또는 한국 날짜 변경 시 표시 색을 초기화한다. 고정 시각으로 장 마감을 합성하지 않는다.
