5. 서버에 코드 적용후 재시작

단, 코드반영 없이 프로세스 무중단으로 환경변수만 적용하여 프로세스를 리로드 하려면 
ubuntu@instance-20260127-2105:~/kiwoom_realtimerank$ pm2 reload kiwoom-service --update-env

* 프로세스 관리
ubuntu@instance-20260127-2105:~/market-through$ pm2 list   -> 현재 실행중인 프로세스 확인
ubuntu@instance-20260127-2105:~/market-through$ pm2 delete market-through-service  -> 특정 프로세스 죽이기
ubuntu@instance-20260127-2105:~/market-through$ pm2 save -> 현재 프로세스 리스트를 저장
pm2 reload market-through --update-env || pm2 start server.js --name market-through -> 특정 프로세스를 재시작
