# 브라우저 안띄워도 자동갱신

상단 톱니바퀴의 **브라우저를 닫아도 서버에서 자동갱신·저장**으로 제어한다. 기본값은 꺼짐이며, 로그인 허용 이메일과 같은 설정 창에서 관리한다. 모든 허용 계정은 상태를 볼 수 있지만 서버 공통 수집의 켜기·끄기는 관리자만 변경한다.

## 실행과 저장

- 접속 여부는 서버 전체에서 합산한다. 어느 컴퓨터에서든 로그인된 Market Through 창·탭이 하나라도 연결되어 있으면 대체 갱신을 중단하고 화면의 기존 자동갱신을 사용한다. 숨김 탭과 최소화한 창도 접속 중으로 판단한다.
- 인증된 SSE 연결로 접속을 유지한다. 마지막 연결이 종료된 뒤 30초가 지나면 서버가 이어받는다. 새로고침과 서버 재시작에도 30초의 재접속 대기 시간을 둔다. 독립 창은 기존 연결 유효시간과 동일한 120초의 접속 유효시간을 사용한다.
- 브라우저가 다시 연결되면 새 대체 조회를 중단하고, 이미 진행 중인 대체 조회가 끝난 뒤 화면의 최초 조회를 시작한다. 중단된 대체 조회 결과는 스냅샷에 반영하지 않는다.
- `data/background-refresh/config.json`에 활성화 상태를 별도로 저장한다. 일반 화면 설정 자동저장이 이 스위치를 덮어쓰지 않는다. 서버 재시작 시 복원한다.
- `user_settings.json` 계열의 기존 서버 설정에서 트레이딩 갱신 주기, 종목, 일봉/분봉, 시장수급 대상, 종목수급 대상을 읽는다. 파일 이름은 기존 설정 마이그레이션 결과를 따른다.
- 30초, 1분, 10분, 1시간 및 당일누적(30초) 주기를 사용한다. 주기는 작업 완료 시점부터 계산한다. 느린 작업이 다른 작업의 다음 주기를 막지 않는다.
- 쏠림율 선택 종목이 없으면 거래대금 순위 첫 종목을 다음 수집부터 사용한다. 선택 종목의 LS 실시간 거래대금 구독은 브라우저 접속 유효시간과 별개로 유지한다.
- 종목조회·거래대금·관심종목 순위, 쏠림율과 종목 가격, 기존/테스트 시장수급, 종목수급과 가격, 거래대금, 신고/신저, 시장 가격, ADR, 심리·변동성의 기존 서버 조회 함수를 호출한다. 과거 더 불러오기 전체를 매 주기 순회하지 않는다.
- 현물·선물의 증권사 조회는 `trading-session.js` 개장 정책을 따른다. 비증권사 지표의 갱신은 해당 소스의 기존 캐시 정책을 따른다.
- 기존 실시간 수집기의 원본 저장은 유지한다. 추가로 `data/background-refresh/snapshots/<대상ID>/latest.json`과 날짜별 `.json.gz`에 조회 결과를 보관한다. 겹치는 시점은 합치고 앞서 저장한 분봉을 유지한다. 인증정보·세션 조회 커서는 보관하지 않는다.
- 브라우저 접속 중에는 대체 갱신 결과를 화면 API 응답으로 치환하지 않고 기존 화면 조회 경로를 사용한다. 과거 조회와 사용자 세션에 연결된 쏠림율 POST 커서는 재사용하지 않는다. 스냅샷은 과거 조회 API 커서를 대체하지 않는다.
- 끄면 새 백그라운드 갱신과 전용 종목 구독 유지를 중단한다. 이미 실행 중인 조회의 응답은 새 스냅샷으로 반영하지 않는다. 기존 독립 수집기나 열린 화면의 조회는 기존 정책을 따른다.

## 확인

`GET /api/background-refresh`는 활성 상태, 대상, 최근 수집 시각, 실패 상태를 반환한다. `PUT /api/background-refresh`는 관리자에게만 허용하며 `enabled` 불리언을 받는다.

검증 파일: `dev/tests/background-refresh.test.cjs`, `dev/tests/background-settings-browser.test.cjs`. 외부 증권사 응답은 테스트 경계에서 대체한다. 실제 장중 수신 및 오라클 배포 검증은 별도로 수행한다.
