# 트레이딩 비교 행

기존 테이블 영역 아래에 3열 비교 행을 둔다.

1. 쏠림율: 키움 / 한투 / LS
2. 거래대금: 키움 / 한투 / LS
3. 종목 수급: 키움 / 한투 / LS
4. 시장 수급: 키움 / 한투 / LS
5. 나머지 기존 카드: 신고가·신저가 / ADR / 변동성 / CNN·하이일드

작은 화면에서는 같은 순서를 유지하며 한 열로 표시한다. 총 16개 차트 카드다. 기존 독립창의 구성은 유지한다. 공통 렌더러와 축을 사용하며 기존 카드의 선택·캔들·확대·과거 조회 정책을 재사용한다. 새 카드도 정보 아이콘과 설명 편집을 지원한다.

## 새 데이터 경로

- LS 쏠림율: 분봉은 종목 `US3`, 시장 `IJ_` 웹소켓을 우선 사용한다. 완료된 연속 분의 누적 거래대금 차이로 비율을 구한다. 누락 구간의 차액을 임의로 분배하지 않는다. REST `t8452` / `t8409`의 실제 분별 거래대금으로 보완한다. 일봉은 `t8451` / `t8429`를 사용한다.
- 한투 거래대금: 분봉은 시장 `H0UPCNT0`의 누적 거래대금(공식 30개 필드 중 인덱스 6)을 우선 사용한다. REST 보완과 과거 기록은 기존 한투 쏠림율 수집기의 `FHKUP03500200` 및 저장 자료를 공유한다. 일봉은 `FHKUP03500100`을 사용한다.
- LS 거래대금: 분봉은 `IJ_` 누적 거래대금, REST 보완은 `t8409` 분별 거래대금 합계다. 해당 일의 처음부터 확보한 자료에 한해 누적 합계를 복원한다. 일봉은 `t8429`를 사용한다.

기존 키움·한투 쏠림율과 키움 거래대금 계산은 유지한다. 키움 분봉은 지수·가격·거래량 기반 추정치, 한투·LS의 새 경로는 보고 거래대금이다. LS 종목은 통합시장이고 시장은 업종지수 기준이며, 시장 지수 거래대금의 KRX+NXT 통합 범위는 미확정이다. 이 차이를 설명에 명시한다. LS 시장 수급 일봉은 LS t1665(투자자)와 t1633(프로그램)의 통합시장 REST 자료를 사용한다. 다른 증권사로 보완하지 않는다.

모든 비교 카드의 가격 캔들은 기존 키움 원천을 공유한다. 거래대금 카드 단위는 조원, 쏠림율은 %다. LS `value`와 한투 업종 `acml_tr_pbmn`을 백만원에서 원으로 환산해 계산한다. 순매수대금이나 주식 수량을 거래대금으로 대입하지 않는다.

## 연결·저장

`broker-stock-supply.js`의 기존 서버 웹소켓 연결에 추가 시세 구독을 함께 올린다. 새 카드별 소켓이나 브라우저별 수집기를 만들지 않는다. 추가 TR 구독이 거부돼도 기존 프로그램 구독을 중단하지 않으며 REST로 보완한다. 승인과 실제 데이터 수신을 구분하고 재연결 시 구독을 복원한다.

시장 두 지수는 서버 시작 후 구독한다. LS 종목은 인증된 쏠림율 조회 선택을 기준으로, 최근 선택한 중복 없는 최대 10종목을 구독하며 15분간 조회가 없으면 제외한다. 브라우저 사용자별 선택 정보는 메모리에만 보관한다.

완료된 웹소켓 분봉은 `data/kis-turnover/`, `data/ls-turnover/`에 원 단위 누적 거래대금으로 저장한다. 저장 필드는 `amount`와 `amount_at`이며 프로그램 수급 필드와 혼용하지 않는다. 기존 저장소의 원자적 저장·완료 일자 무손실 압축을 재사용한다. 현재 분·미래·역순·다른 종목 메시지는 제외한다. REST 과거 캐시와 실시간 저장 조회를 분리해 캐시가 살아 있어도 새 분이 표시되게 한다.

## 검증 기록

2026-10-26 LS 실제 REST에서 `t8451`, `t8452`, `t8429`, `t8409`의 응답 코드 `00000`을 확인했다. 코스피 `t8409` 381개 분별 금액 합계 12,991,168은 `t8429` 당일 금액과 일치했다. 삼성전자 통합 일봉 금액은 3,681,171이었다(원본 백만원). 근거는 키·토큰을 제외한 `dev/output/broker-turnover-probe.json`에 있다.

LS 일반 분봉의 첫 시각은 09:01로 종료 시각 표기다. 이를 공통 차트 시작 시각 09:00에 맞추고, 15:30 동시호가 봉은 별도 실행으로 유지한다. 실제 서버는 `t8451.qrycnt`에 숫자형을 요구하므로 숫자로 전송한다.

공식 웹소켓 필드와 요청 형식을 확인하고 가짜 전송을 사용한 자동 검증을 통과했다. 실제 조회 검증 시점은 장 마감 후여서 새 시세 TR의 장중 실수신·저장까지는 확인하지 못했다. 운영 서버를 재시작하거나 배포하지 않았다. 적용에는 서버 재시작과 화면 새로고침이 필요하다.

주요 자동 검사: `broker-comparison.test.cjs`, `broker-stock-supply.test.cjs`, `kis-concentration-chart.test.cjs`, `rank-market-supply-page.test.cjs`, `kis-concentration-chart-ui.test.cjs`, `rank-turnover.test.cjs`.

공식 명세: [LS](https://openapi.ls-sec.co.kr/apiservice), [한투 실시간 시세](https://github.com/koreainvestment/open-trading-api/blob/main/examples_user/domestic_stock/domestic_stock_functions_ws.py).


## 2026-10-26 원천 분리 점검

캔들 가격 및 거래일·시간축·선택 종목 공유는 유지하되, 비교 지표의 숫자는 각 증권사 원천만 사용한다. 오류·미제공일 때 다른 증권사 수급이나 쏠림율을 대입하지 않는다. 비교 카드 12개를 일봉·분봉 경로 모두 점검했다.

- 쏠림율: 키움은 키움 종목/업종 가격·거래량 기반 계산, 한투는 한투 종목·업종 거래대금 REST, LS는 LS 종목(t8451/t8452·US3)과 업종(t8429/t8409·IJ_) 거래대금이다. LS는 참조 응답의 value/stock_turnover/market_turnover를 모두 LS 값으로 교체한다. 참조 시간축에 LS가 없으면 결측이다.
- 거래대금: 키움은 기존 키움 계산, 한투는 업종 FHKUP03500100/FHKUP03500200·H0UPCNT0, LS는 t8429/t8409·IJ_다. 공유 참조의 거래대금은 한투·LS 카드에 사용하지 않는다.
- 종목수급: 키움은 ka10060·ka90013/ka90008, 한투는 FHPTJ04160001/HHPTJ04160200·FHPPG04650201/자체 프로그램 WS, LS는 t1717·t1637/UPH다. 같은 종목 목록과 캔들만 공유하며 개인 미제공 등은 그대로 미제공이다.
- 시장수급: 키움은 ka10051·ka90010/ka90005, 한투는 FHPTJ04040000/FHPTJ04030000·FHPPG04600001/FHPPG04600101, LS는 일봉 t1665/t1633 REST와 분봉 UBT/UPM/BMT 및 t1602 보완이다. LS 일봉의 한투 재사용을 제거했고 일봉 제공자 누락 시 다른 원천으로의 기본 경로를 차단한다.

LS 일봉 실제 2026-10-26 코스피 통합 조회: t1665 sa_08=-285, sa_17=-7012, sa_18=6883(억원 → 공통 백만원 x100), t1633 tot3=-532455(백만원 x1). 화면은 모두 억원으로 환산한다. t1665는 수치1·일1, t1633은 금액0·수치0·일1·직전증감0이다. 10월23일/26일을 새 제공자 경로에서도 검증했다. 실제 조회 증거는 dev/output/ls-market-daily-probe.json(로컬 전용)에 기록한다.

키움 350ms는 API 응답 필드가 아니라 앱이 HTTP 요청 종료 후 단일 큐에 적용하는 호출 간격이다. 한 번에 수백 개 투자자 날짜를 요청하는 최초 일봉 조회는 오래 걸릴 수 있다. 최근 날짜부터 중간 표시하도록 순서를 변경했으며, 이력 캐시와 중복 작업 공유는 유지한다. 호출 제한을 확인하지 않고 간격을 제거하지 않는다.


### 2026-10-26 HTTP 경계 재점검 및 결측·0 구분

일봉 제공자 추가 이후에도 `/api/ls-market-supply/chart` 라우트에 남아 있던 일봉 한투 분기를 발견하여 제거했다. 이제 day/minute/기본 모드 모두 LS 서비스로 전달하며 실제 서버 라우트 핸들러를 분리 실행하는 회귀 검사를 추가했다. 제공자 단위 검사만으로 실제 HTTP 연결까지 검증됐다고 판단했던 이전 보고를 정정한다.

LS 자체 코스피 일봉 600봉(2024-05-07~2026-10-26)은 네 항목 모두 결측0·실제 숫자0 응답0·비영값600이었다. 한투 삼성전자 프로그램 통합 일봉은 같은600봉 중 212개가 원천0,388개가 비영값이며 최초 비영값은2025-03-24였다. 한투 KRX 같은과거표본은 비영값을 반환했으므로 통합의 연속0을 실제순매수0으로 확정하지 않는다. 한투 시장 프로그램 통합2024년5월표본은0건이다. 범위가 다른 KRX 자료로 자동 보완하지 않는다. 증거 파일은 dev/output/program-history-completeness.json, stock-history-zero-validation.json, ls-market-full-validation.json이다.
