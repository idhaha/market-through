# 트레이딩 자동 갱신 시간

자동 수집·웹소켓 연결과 트레이딩 탭의 주기 갱신에 `trading-session.js`의 공통 개장 정책을 적용한다. 초기 화면 조회와 수동 과거 조회는 별도로 허용한다. 증권사 외부의 CNN·변동성 갱신은 유지한다.

- 현물: 한국 시간 08:00 이상~20:00 미만.
- 선물: 08:45 이상~15:45 미만, 18:00 이상~익일 06:00 미만. 휴장 구간 15:45~18:00과 06:00~08:45에는 자동 조회하지 않는다.
- 야간은 시작일의 개장 여부로 판단해 금요일 밤~토요일 새벽을 포함한다. 다음 날이 공휴일이어도 시작일이 개장일이면 야간장은 이어진다. 공휴일 저녁에 새로 시작하는 야간장은 휴장한다. 특별 야간 휴장 예외나 당일 긴급 휴장 JIF 판정은 별도 구현이 필요하다.
- 국내휴장일조회 `CTCA0903R`의 `bass_dt`/`opnd_yn`을 사용한다. 날짜를 코드에 고정하지 않는다. 기준일은 전날부터 요청해 자정 전후 판정에 필요한 날짜를 확보한다.
- 개장일 정보는 `data/trading-session/calendar.json`에 저장한다. 당일 검증 성공 후에는 반복 조회하지 않는다. 날짜가 바뀌면 다시 검증한다. 실패 시 자동 갱신은 보류하고 15분 간격으로 재시도한다. 토·일 장외에는 휴장일 API도 조회하지 않는다. 당일 검증 이후 새로 발표된 긴급 변경까지 즉시 반영하는 기능은 없다.
- `/api/trading-session`은 외부 API를 호출하지 않고 현재 판정을 반환한다. 브라우저는 이를 최대 분당 한 번 확인한다. 순위표·현물 차트는 현물 개장 중에만, 선물 차트는 선물 개장 중에만 자동 갱신한다.
- 분봉 공통 시간축도 같은 개장일 달력을 사용한다. 개장일 08:00~24:00, 전날이 개장일인 날의 00:00~06:01 관측을 유지하고 나머지 주말·공휴일 구간을 생략한다. 과거 달력이 없는 조회 범위는 `/api/trading-session/calendar?from=YYYY-MM-DD&to=YYYY-MM-DD`로 보완·저장한다. 확인되지 않은 평일은 임의로 휴장 처리하지 않는다. 달력 도착 시 줌·스크롤의 시각 기준은 유지하며 공통 축을 다시 그린다.
- 웹소켓은 장외 연결을 종료한다. LS 현물 UBT/UPM과 주간 BMT 구독도 나눠 현물과 선물의 운영 시간이 다를 때 불필요한 구독을 유지하지 않는다.
- 장외에는 기존 지수 캔들 캐시를 TTL이나 자정 경과만으로 재조회하지 않는다. 캔들 주기·시장·연속조회 페이지는 구분한다. 브라우저 캐시도 장외에는 유효한 기존 데이터를 유지하고 배경 재검증을 중단한다.

## 개장이 늦은 날

휴장일 API는 개장 여부만 주고 개장·마감 시각은 주지 않는다. 늦게 여는 날은 `market-open-delay.js`가 판단한다. 2026-11-19 수능일에 업종지수 분봉이 10:00부터 시작해 시장 누적 거래대금(쏠림율 누적, LS 거래대금 분봉)이 비었던 일이 계기다.

- 수능일: 매년 한국거래소 공지(2026년은 11/05)가 나오면 관리자가 설정(⚙) 창의 "올해 수능일" 칸에 날짜만 입력한다(수능일은 개장·마감 모두 60분 늦다, 정규장 10:00~16:30). 서버가 `data/trading-session/calendar.json`의 `openDelays`에 `reason: '수능'`으로 저장하고, `market-open-delay.js`가 코드 기본값 표와 합쳐 배포 없이 바로 쓴다(같은 날이면 calendar.json이 이긴다). 한 해에 하나만 두며 같은 해를 다시 입력하면 바꾼다. API: `GET/POST /api/trading-session/exam-days`, `DELETE /api/trading-session/exam-days/:date`(저장·삭제는 관리자만). 그 밖의 지연일은 코드 표에 더하고 배포한다.
- 수능일 미등록 알림: 10/20부터 그해 `reason: '수능'` 줄이 생길 때까지(최대 12/31) `/api/trading-session`이 `examReminder` 문구를 보내고, 메인 화면 맨 위 바(제목과 오른쪽 버튼 사이 빈 칸)에 "⚠ 수능일 미등록"이 뜬다. 서버 로그에도 하루 한 번 `[개장 지연]`을 남긴다. 날짜가 아니라 reason으로 찾으므로 수능이 12월인 해나 11월의 다른 지연일과 섞이지 않는다. "오늘 숨기기"는 그 브라우저에서 그날만 숨긴다. 독립창에는 띄우지 않는다.
- 새해 첫 거래일: 표에 적지 않는다. 개장일 달력에서 1월 1일부터 그 전날까지 평일이 모두 휴장으로 확인된 첫 개장일을 10:00 개장(마감은 15:30 그대로)으로 본다. 달력에 없는 평일이 끼면 판단하지 않는다.
- 표에 없는 지연일: 오늘 LS 업종지수 첫 분봉이 09:00보다 늦으면 `[개장 지연]` 경고를 하루 한 번 남긴다. 표에 더하고 배포하면 이미 받은 자료로 누적을 다시 계산한다.
- 아직 표를 쓰지 않는 곳: ADR 분봉 저장(09:00~15:30), 선물 주간 수집(08:45~15:45), 주식선물 수집(08:45~16:20)은 고정 시각이라 수능일 마감 연장분을 받지 못한다(2026-11-19 확인).
