# 트레이딩 자동 갱신 시간

자동 수집·웹소켓 연결과 트레이딩 탭의 주기 갱신에 `trading-session.js`의 공통 개장 정책을 적용한다. 초기 화면 조회와 수동 과거 조회는 별도로 허용한다. 증권사 외부의 CNN·변동성 갱신은 유지한다.

- 현물: 한국 시간 08:00 이상~20:00 미만.
- 선물: 08:45 이상~15:45 미만, 18:00 이상~익일 06:00 미만. 휴장 구간 15:45~18:00과 06:00~08:45에는 자동 조회하지 않는다.
- 야간은 시작일의 개장 여부로 판단해 금요일 밤~토요일 새벽을 포함한다. 다음 평일이 휴장일인 경우 야간도 중단한다. 특별 야간 휴장 예외나 당일 긴급 휴장 JIF 판정은 별도 구현이 필요하다.
- 국내휴장일조회 `CTCA0903R`의 `bass_dt`/`opnd_yn`을 사용한다. 날짜를 코드에 고정하지 않는다. 기준일은 전날부터 요청해 자정 전후 판정에 필요한 날짜를 확보한다.
- 개장일 정보는 `data/trading-session/calendar.json`에 저장한다. 당일 검증 성공 후에는 반복 조회하지 않는다. 날짜가 바뀌면 다시 검증한다. 실패 시 자동 갱신은 보류하고 15분 간격으로 재시도한다. 토·일 장외에는 휴장일 API도 조회하지 않는다. 당일 검증 이후 새로 발표된 긴급 변경까지 즉시 반영하는 기능은 없다.
- `/api/trading-session`은 외부 API를 호출하지 않고 현재 판정을 반환한다. 브라우저는 이를 최대 분당 한 번 확인한다. 순위표·현물 차트는 현물 개장 중에만, 선물 차트는 선물 개장 중에만 자동 갱신한다.
- 웹소켓은 장외 연결을 종료한다. LS 현물 UBT/UPM과 주간 BMT 구독도 나눠 현물과 선물의 운영 시간이 다를 때 불필요한 구독을 유지하지 않는다.
- 장외에는 기존 지수 캔들 캐시를 TTL이나 자정 경과만으로 재조회하지 않는다. 캔들 주기·시장·연속조회 페이지는 구분한다. 브라우저 캐시도 장외에는 유효한 기존 데이터를 유지하고 배경 재검증을 중단한다.

공식 휴장일 API 예제: https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/chk_holiday/chk_holiday.py
