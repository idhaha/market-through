# 시장수급(테스트)

2026-10-31: 시장수급 카드를 재사용해 마지막 행에 테스트 카드를 추가했다. 주·야간 선택 없이 시간순으로 이어 표시한다. 시장·봉·확대 구간·드래그·호버·과거 조회는 기존 카드의 공통 동기화 정책을 따른다. 현물 선택은 기존 통합 카드 원천을 유지한다.

- 선물 대상: KOSPI200 `K2I`, KOSDAQ150 `KQI`. 주간 `D`와 야간 `N`을 하나의 응답으로 병합한다. 분봉 수급은 세션별 원본 누적값을 유지하며 임의 누적 보정은 하지 않는다. 일봉 주간 수급은 일반 시장수급과 같은 공급자·조회 범위를 사용한다. 투자자별로 주간값을 표시하고 같은 LS 거래일의 야간값이 있으면 합산한다(0도 유효). 주간값이 없으면 결측으로 둔다. 야간 일봉도 그 범위를 끝까지 조회하며, 수급의 과거 조회 커서는 가격 캔들 범위와 분리한다. 일봉 가격은 야간 시가·주간 종가와 두 세션의 고가/저가를 사용한다.
- 시간축은 다른 차트와 공유한다. 야간 표시 시 공통 분봉 축이 자정 전후의 실제 달력 시각을 유지한다. 미거래 시간도 축에 남기며 그 구간의 수급·캔들은 결측으로 둔다. 0이나 보간값, 빈 시간에 걸친 연결선을 만들지 않는다.
- 수급: 일봉 `t8462`, 분봉 `t8463`. 금액은 기존 LS 일봉과 같은 원본 ×100 백만원으로 변환한다. HTS 대조 필요 안내를 표시한다. 계약 수량을 금액으로 사용하지 않으며 프로그램 수급은 생성하지 않는다.
- 주간 분봉에서 LS가 제공하지 않은 분은 기존 시장수급 카드의 한투 저장 이력을 읽어 보완한다. 백만원 단위와 관측 시각을 그대로 사용하고, 주간 시간 밖 자료와 프로그램은 제외한다. 일봉·야간에는 이 보완을 적용하지 않는다. 저장 이력은 LS 원본 파일에 섞어 저장하지 않으며 화면에 한투 주간 보완 출처를 표시한다.
- 가격: 주간 일봉 `t8466`, 주간 분봉 `t8465`, 야간 일봉 `t8459`, 야간 분봉 `t8461`. 주간 `t8467`, 야간 `t8455` 마스터에서 스프레드를 제외한 최근월물을 선택한다. 연속선물이 아니며 현재 최근월물의 과거 가격만 제공한다.
- 야간 분봉 `t8461`은 날짜가 없으므로 같은 조회의 `t8463.date/time`을 기준으로 자정 전후를 복원한다. 날짜 기준이 없으면 가격을 만들지 않는다. `t8463.datetime`이 명세와 달리 8자리로 반환되는 경우에도 `date/time`으로 처리한다.
- 야간 분봉은 `ls-night-supply.js` 수집기가 서버 시작 시 최근·전일 세션을 보완하고, 평일 야간부터 다음날 06:03까지 분당 한 번 수집한다. 완료된 분의 마지막 원천 관측값을 사용하며 `data/market-supply/FUTURE/`와 `FUTKQ0/`의 기존 주간 파일에 함께 저장한다. 자정 이후는 실제 달력 날짜 파일에 저장한다. 기존 압축·과거 보관 정책을 유지하고 오래된 값을 자동 삭제하지 않는다. 백만원 단위이며 `source=LS`, `session=N`, 투자자별 원천 시각을 함께 기록한다.
- 서버 시작 시 테스트 전용 파일에 이미 저장한 야간 관측도 공통 저장소로 반영한다. 기존 주간 기록과 더 최신 원천 관측값은 유지한다. 주간 한투 수집은 08:00~15:46으로 제한해 야간 LS 수급과 충돌하지 않도록 한다.
- 서버에 공통 저장소가 연결되어 있으면 테스트 카드의 분봉 조회·더 불러오기는 수급 TR을 호출하지 않는다. 주간은 기존 한투 저장값, 야간은 LS 저장값을 읽는다. 최근·전일 API 보완은 별도 수집기만 수행한다. 과거 선물 가격은 공통 시간축 범위에 맞춰 t8465의 날짜·시간 연속키로 조회한다. 갱신 완료 응답에서도 이미 읽은 과거 수급·캔들을 유지한다. 날짜 지정이 불가능한 t8461의 과거 야간 가격은 만들어 채우지 않는다.
- 야간 수급은 읽은 최근 3개 달력 날짜 파일의 모든 저장 세션을 반환한다. 최신 야간만 고르는 필터를 적용하지 않으며, 더보기 커서는 이 파일 범위 이전을 가리킨다. 주간과 최신 야간 사이에 있는 이전 야간도 같은 저장 시각·투자자별 값으로 표시한다.
- 일봉 날짜는 LS 원본 거래일을 유지하고 야간을 임의로 달력 하루 이동하지 않는다. 과거 더보기는 해당 날짜 이전 구간을 조회한다.
- 일반 시장수급 카드의 선물 분봉은 `/api/market-supply/chart?prices=0`으로 저장 수급만 먼저 읽는다. 현물 대용 캔들의 연속조회가 끝나기를 기다리지 않으며, 가격은 기존 `/api/adr/candles` 범위 조회로 별도 보완한다. `prices`를 생략한 API 호출은 기존 가격 포함 응답을 유지한다.
- 가격 실패 시 수급을 유지하고 오류를 표시한다. 수급 실패 시에도 날짜가 있는 주간 가격은 표시할 수 있다. 현물 가격으로 대체하지 않는다.

실조회 결과: 두 시장 모두 주간/야간 일봉의 수급 및 가격, 야간 분봉 수급 정상 반환. 야간 분봉 가격 `t8461`은 분구분·소량 요청 비교에서도 HTTP 500을 반환했다. 이 제한은 카드에 표시하며 정상 동작으로 간주하지 않는다.

검증: `node --test dev/tests/ls-futures-test.test.cjs`, `node dev/tests/ls-futures-test-browser.cjs`. 기존 통합 카드 회귀 검증은 `node dev/tests/combined-market-supply.test.cjs`를 사용한다.

로딩: 분봉도 `progressive=1`로 요청한다. 야간 수급을 먼저 조회하고 각 세션의 수급이 도착하면 가격 완료 전 중간 결과를 표시한다. 화면은 같은 진행 중 작업을 폴링하며 중복 TR을 만들지 않는다. 요청 제한은 TR별 대기열과 다음 요청의 1.1초 대기로 유지하며, 완료된 응답 반환에는 이 대기를 붙이지 않는다. 새로고침 중에는 이전 수급·캔들을 유지하고 최종 응답에서 갱신한다.
