# Rank 쏠림율 차트

## 한투 비교 카드 (2026-10-25)

메인 화면 맨 아래 CNN 카드 오른쪽(3행 3열)에 `쏠림율[한투]`를 추가했다. 기존 쏠림율과 같은 초기화·그리기 코드를 공유한다. 종목 선택은 두 방향으로 함께 바뀌고 일/1분 전환, 당일·과거 조회, 확대·축소·휠·드래그·슬라이더, 호버와 캔들 표시 및 설정 복원은 공통 정책을 따른다. 기존 쏠림율의 키움 계산식은 유지한다. 독립창 배치는 유지한다.

저장 분리 정책: 한투 원본은 한투 전용 `data/kis-concentration/`에만 저장한다. 기존 키움 쏠림율 데이터와 병합하거나 덮어쓰지 않는다. 한투 거래대금 캐시와 기준 차트 조회 세션도 별도 서비스 인스턴스가 소유한다. 화면 조작과 기준 캔들을 공유하는 것은 원천 데이터 저장 통합을 의미하지 않는다.

인증된 `POST /api/kis-concentration-chart`는 기존 차트와 같은 요청·응답 형식 및 사용자별 조회 커서를 사용한다. 시간축과 하단 종목 OHLC는 기존 키움 기준 페이지를 유지하며 거래대금과 비율만 한투로 계산한다. 종목은 기존 통합시장 정책에 맞춰 `UN`을 요청한다. 업종은 `U`, 코스피 `0001`/코스닥 `1001`이다. 종목 통합시장과 업종 집계 범위가 동일하다고 확정하지 않는다.

- 분봉: 종목 `FHKST03010230`의 누적 거래대금 차분(원) / 업종 `FHKUP03500200`의 누적 거래대금 차분 × 1,000,000(원) × 100(%).
- 일봉: 종목 `FHKST03010100`의 실제 일 거래대금(원) / 업종 `FHKUP03500100`의 실제 일 거래대금 × 1,000,000(원) × 100(%).
- 차분은 일자별로 초기화한다. 최초 종목 08:00/업종 09:00은 당일 누적 0 기준, 그 외 최초 행이나 중간 분봉 누락은 `null`이다. 종가 단일가 구간의 무체결 행 생략(15:19 또는 15:20 → 15:30)은 누적 차분을 허용한다.
- 업종 특수 시간값 `888888`/`999999`는 저장하되 실제 15:30 분봉에 합치지 않는다. 음수 차분·분모 0·없는 데이터는 가격×거래량이나 보간으로 대체하지 않는다.
- 한투 업종 1분봉은 최신 102행 제한이 있어 새로 받은 누적 원본을 `data/kis-concentration/<업종>/<YYYYMMDD>.json`에 시각별 병합 저장한다. 서버 시작 시 화면과 무관한 수집기를 시작하며 한국시간 평일 08:00~20:02에 코스피·코스닥을 1분마다 수집한다. 시작 시에도 즉시 한 번 실행하고, 중복 시작·진행 중 중복 수집을 막는다. 장 마감 뒤 특수행 갱신도 보존한다. 주말·수집시간 밖은 API를 호출하지 않고, 휴장일에 반환된 전 거래일 자료를 당일로 저장하지 않는다. 한 시장 실패 시 다른 시장은 계속 수집하고 다음 주기에 재시도한다. 차트 조회·화면 자동 갱신도 같은 한투 전용 파일에 최신 원본을 병합하며 요청 캐시를 공유한다. 기존 키움 저장소와는 분리한다. 서버가 중지된 동안 조회 한도보다 오래 지난 분봉은 복원할 수 없어 공백으로 표시한다. 종목의 과거 분봉은 날짜·시각으로 조회하고 페이지/요청을 캐시한다.

상시 수집 검증: 화면·키움 기준 조회 없이 두 시장 저장, 시작 즉시 및 60초 주기, 중복 시작/실행 방지, 시간대·주말·전 거래일/미래 행 제외, 시장별 실패 격리·다음 주기 재시도, 저장 파일 복원과 기존 계산을 확인했다. 서버 시작 때 기존 한투 수집기와 토큰을 동시에 요청해도 인증 요청 한 건을 공유하고 실패 후 재시도한다. 관련 Node 테스트 29개 통과. 서버 재시작 후 적용되며 서버 프로세스가 실행되어 있어야 한다.

검증: 새 서버 및 기존 계산·공통 축/과거 조회 Node 테스트 32개 통과. 새 카드 브라우저 테스트에서 CNN 오른쪽 위치, 높이 286px·플롯 오프셋, 출처 한투, 두 방향 종목 선택, 일/분·캔들·확대 동기화, 기존 갱신 주기 참여, 한투 오류 시 이전 값 및 키움 카드 유지가 통과했다. 기존 카드 하단 레이아웃 테스트도 통과했다. 실제 API로 10/23 13:54 삼성전자 UN 기준 13.5878616%, 10/21~23 일봉 계산을 확인했다. 기존 `concentration-chart-ui.test.js`는 이번 변경과 무관한 이전 설정 구조(`debugOpen`) 기대값에서 실패하여 전체 통과로 보고하지 않는다.

## 데이터와 계산

- 종목 분봉: `ka10080`, `stk_min_pole_chart_qry`, `cntr_tm`.
- 종목 일봉: `ka10081`, `stk_dt_pole_chart_qry`, `dt`.
- 시장 분봉: `ka20005`, `inds_min_pole_qry`, `cntr_tm`.
- 시장 일봉: `ka20006`, `inds_dt_pole_qry`, `dt`.
- 모든 차트 요청은 `/api/dostk/chart`에 POST한다. 종목은 통합 거래소 코드 `<code>_AL`, 수정주가 구분 `0`을 사용한다. 일봉 기준일은 한국 날짜다.
- 시장은 `ka10100`의 유효한 시장코드 또는 같은 API로 만든 기존 서버 캐시에서 확인한다. 코스피(`0`)는 업종 `001`, 코스닥(`10`)는 업종 `101`을 사용한다. 시장 미확인 시 기본 시장을 추정하지 않는다.
- 일봉은 종목(`ka10081`)과 업종(`ka20006`) 모두 실제 거래대금 `trde_prica`를 사용한다. 두 값은 백만원 단위이며 API에서는 원 단위(`trde_prica × 1,000,000`)로 반환한다. 거래대금 필드가 없거나 유효하지 않으면 가격 × 거래량으로 대체하지 않고 계산 불가로 처리한다. 분봉의 종목 거래대금은 `abs(int(cur_prc)) * int(trde_qty)`를 사용한다. 분봉의 업종 거래대금은 사용자가 지정한 추정식 `(abs(int(cur_prc)) / 100) * (int(trde_qty) * 10,000)`을 적용한다. 이는 기존 업종 가격 × 거래량 계산값의 100배이며, 쏠림율은 기존의 1/100로 바뀐다. 실제 거래대금 필드를 사용하는 일봉과 달리 분봉 업종 거래대금은 사용자 지정 추정값이다. 쏠림율은 종목 봉 거래대금 / 시장 봉 거래대금 × 100이며 소수값을 유지한다. 테이블의 누적 쏠림율(`ka20001`)과는 데이터 원천이 다르다.
- 분봉은 09:00 이전을 제외하고 한국 거래일과 09:00 기준 시간 구간으로 맞춘다. 같은 구간의 시장 데이터가 없거나 분모가 0·유효하지 않은 값이면 API는 `null`로 반환한다. 분봉 차트는 이런 봉을 제외해 X축의 빈 공간 없이 유효한 봉만 이어서 표시한다. 일봉의 계산 불가 값은 선을 끊고 툴팁에 -로 표시한다.
- 종목 분봉 간격은 명세의 `1, 3, 5, 10, 15, 30, 45, 60`을 사용한다. 업종에서 직접 지원하지 않는 15·45분은 5분봉, 60분은 30분봉을 합쳐 `(마지막 현재가 / 100) × (합산 거래량 × 10,000)`으로 계산한다. 시간 구간은 09:00을 기준으로 맞추며 거래일을 넘겨 합산하지 않는다.

## 연속조회

인증된 `POST /api/concentration-chart`에 `{ code, mode: 'minute' | 'day', interval, cursor? }`를 전송한다. 응답은 `{ success, market, mode, interval, points: [{ time, value, stock_turnover, market_turnover, stock_price, stock_volume, market_price, market_volume }], cursor, has_more, history_pending }`다.

최초 요청은 종목 API의 기본 한 페이지 전체를 가져온다. 종목·시장 각각의 응답 헤더 `cont-yn` 및 `next-key`를 별도로 보관하고 시장 과거 데이터를 종목 기간까지 조회한다. 한 요청의 시장 추가 조회는 최대 12페이지로 제한한다. 더 필요한 시장 과거 데이터는 `history_pending`으로 알리며 추가조회 버튼으로 이어서 가져온다. 완료된 시장 기록만으로는 종목의 다음 페이지를 먼저 가져오지 않는다.

커서는 사용자·종목·봉 종류·간격에 귀속된 서버 메모리 조회 세션이다. 세션 유효기간은 마지막 성공 조회부터 30분이며 서버 재시작 시 만료된다. 각 원천의 같은 날짜·시간 봉은 중복 제거한다. 실패한 연속조회는 마지막 성공 커서로 재시도한다. 세션당 원천별 50,000봉을 넘으면 간격을 늘리도록 안내하며 기존 기록을 임의로 잘라내지 않는다.

## 표시와 조작

일 버튼을 선택하면 분 간격 버튼이 비활성화된다. 최초 조회와 추가조회 성공 직후는 불러온 전체 과거 데이터를 표시한다. 오른쪽 아래 `+`/`−`로 확대·축소하고 하단 슬라이더로 과거 구간을 이동한다. 주요국지수 차트처럼 차트 내부 왼쪽→오른쪽 드래그는 선택 범위를 확대하고 오른쪽→왼쪽 드래그는 전체 구간으로 복원한다. 10px 이하 움직임은 클릭으로 처리하며, 드래그 중 선택 영역을 표시하고 외부에서 놓거나 포인터 취소 시에도 상태를 정리한다. 분봉은 같은 날짜 전체 또는 120봉 이하의 확대 구간에서 분 없이 시간만(09·10 등) X축에 표시한다. 화면 폭이 충분하면 매시 표시하고 좁은 화면에서는 겹치지 않게 시간 눈금을 간격 조절한다. 더 넓은 여러 날짜 구간과 일봉은 날짜를 표시한다. 하단 기간과 툴팁은 정확한 분을 유지한다. 분봉의 날짜 경계와 일봉의 월 경계에 회색 세로 점선을 표시한다. 구분선은 최소 32px 간격을 확보해 겹침을 방지한다. 날짜는 연도를 생략한 MM/DD 형식이다. Y축은 기본 0~70%에 10%마다 회색 가로 점선을 표시하며, 값이 70%를 넘으면 표시 구간의 데이터에 맞춰 범위와 눈금 간격을 자동 확대한다. 로딩 중 시장 표기를 유지하고 표기 영역의 너비를 고정해 버튼 위치가 움직이지 않도록 한다. 로딩 문구 대신 기존 차트에 2px 블러와 약한 투명도를 적용하고, 완료 시 새 데이터로 갱신한다. 첫 조회 중에는 문구 없이 격자만 블러 처리한다. 상태·오류 안내는 차트 안에 절대 위치로 표시하여 차트 높이와 위치가 변하지 않도록 한다. 오른쪽 임시 수치 검증 패널과 정상 조회 후 안내 문구는 제거했다. 현재 쏠림율은 표시 구간과 관계없이 불러온 마지막 봉 기준으로 헤더 우상단의 쏠림율 문구 오른쪽에 표시한다. 그래프에는 마지막 표시 봉의 점만 표시하며, 세로축은 최댓값 위에 15%의 여유를 확보한다. 차트 패널의 데스크톱 폭은 테이블 영역의 50%이며 휴대폰에서는 화면 너비 안에 맞춘다. 추가조회 아이콘은 제공된 이미지처럼 두 개의 회색 봉과 오른쪽 아래 + 표시를 SVG로 그린다.

빠르게 종목·봉을 바꾸면 이전 브라우저 요청을 취소하고 오래된 응답이 최신 차트를 덮어쓰지 못하도록 한다. 조회 오류 시 초기 요청은 일/분 버튼으로, 추가 요청은 추가조회 버튼으로 재시도할 수 있다.

## 자동 갱신

일봉·분봉 모두 Rank 우측 상단의 기존 자동 갱신 타이머에 맞춰 현재 데이터를 다시 조회한다. 주기 변경, Rank 수동 조회, 전체 조회에도 연결된다. 종목·봉 종류·분 간격은 그대로 유지하고, 최신 페이지로 현재 봉을 교체하면서 이미 불러온 오래된 기록은 보존한다. 확대 구간은 시작 시간 기준으로 유지하며 최신 끝 구간을 보고 있으면 새 끝 구간을 따라간다. 별도의 차트 타이머는 만들지 않는다. 이미 조회 또는 드래그 중이거나 캡처 중이면 해당 갱신을 건너뛴다. 자동 갱신 실패 시 기존 차트와 현재 값을 유지하고 다음 주기에 재시도한다.

분봉 X축은 전체 보기에서 시간만 표시하고, 확대 후 인접 눈금 사이에 충분한 여유가 있으면 30분 간격(09:00·09:30 등)으로 표시한다. 화면이 좁으면 매시 또는 더 넓은 간격을 유지한다.

분봉 X축 눈금에는 시·분 접미사를 붙이지 않는다. 매시 간격은 09·10처럼, 30분 간격은 09:00·09:30처럼 표시한다.

## 5분봉 원본 비교 디버깅 (2026-10-08)

차트 오른쪽에 삼성전자(ka10080, 통합 거래소 005930_AL)와 코스피(ka20005, 업종 001)의 최근 완료된 5분봉 5개를 각각 최신순으로 표시한다. cntr_tm은 봉 시작 시각이며 시작+5분이 지난 봉만 포함한다. cur_prc·trde_qty는 부호·선행 0을 포함한 원본 값을 그대로 표시한다. 두 원천을 따로 표시해 시장 데이터 누락을 숨기지 않는다. 비교 대상은 차트 선택 종목·간격과 독립적이다.

최초 화면 표시 때 조회하고 5분 경계 2초 뒤마다 재조회한다. 진행 중 봉은 제외하고 조회 실패 시 기존 표를 유지한다. 중복 조회·숨김 문서·캡처 중 조회를 건너뛰며 문서 복귀 시 재조회한다. 디버깅용 타이머는 Rank 주기의 차트 갱신 타이머와 별도다. 데스크톱 패널 폭은 기존 절반 폭에 360px를 추가하며 휴대폰은 표를 차트 아래에 배치한다.

차트 API의 minute/interval=5 응답은 debug_five_bars={fetched_at, stock, market}를 추가한다. stock·market 배열 항목은 {cntr_tm, cur_prc, trde_qty} 원본 필드이며 다른 봉 종류·간격에서는 debug_five_bars=null이다. 디버깅 요청은 code=005930, mode=minute, interval=5를 고정한다. 운영 서버는 새 응답 필드 반영을 위해 재시작해야 한다.

## 차트 종목 직접 입력

차트 종목명은 편집 가능한 입력란이다. 정확한 종목명 또는 6자리 종목코드를 입력하고 Enter를 누르면 테이블 표시 여부와 무관하게 해당 종목 차트를 조회한다. 현재 일/분 및 간격 설정은 유지한다. 실패 시 기존 선택과 차트를 유지하며 오류를 안내하고, 검색 중 테이블 종목을 선택하면 늦은 검색 결과를 무시한다.

인증된 GET /api/concentration-stock?q=입력값은 {success:true, stock:{code,name,market}}를 반환한다. 이름 조회는 ka10099의 코스피/코스닥 전체 연속조회 목록으로 정확히 일치하는 종목을 찾고 성공 목록을 24시간 메모리 캐시한다. 코드 조회는 ka10100으로 이름과 시장을 검증한다. 빈 입력 400, 미일치/모호한 이름/지원하지 않는 시장 404, 외부 오류 502다. 최초 이름 조회는 목록을 가져오는 시간이 필요하다. 서버 재시작이 필요하다.

### 디버깅 대상 및 조회 방식 수정

이전 삼성전자 고정 규칙을 대체한다. 디버깅은 테이블 또는 직접 입력으로 선택한 종목과 해당 시장(코스피 001 / 코스닥 101)의 완료된 최근 5개 5분봉을 표시한다. 선택 즉시 재조회하고, 다른 종목의 늦은 응답을 취소·무시한다. 차트 봉 설정과 무관하게 디버깅은 5분봉을 사용한다.

POST /api/concentration-chart에 {code:선택종목, mode:"minute", interval:5, debug_five:true}를 보내면 최신 원천 페이지 두 개만 조회하여 {success,market,debug_five_bars}를 반환한다. 과거 기록 보충·차트 커서 생성은 생략한다. 빈 데이터·조회 실패·서버 응답 필드 누락을 표에 안내한다. 실패 시 같은 종목의 기존 값은 보존한다. 새 서버 코드 적용에는 재시작이 필요하다.

### KRX 종료 후 디버깅 갱신 중지

한국 시간 평일 09:00~15:30에만 디버깅을 조회한다. 15:30 경계의 예약 조회는 2초 뒤 마지막 완료 봉을 한 번 가져오고 중지한다. 이후 예약·종목 선택·문서 복귀로도 디버깅을 조회하지 않으며 기존 표를 유지하고 갱신 중지 상태를 표시한다. 다음 평일 정규장 시간에 예약 조회가 재개된다. 일반 쏠림율 차트의 Rank 주기 갱신 규칙은 유지한다. 이 시간 게이트는 정규 시간 기준이며 휴장일·특별 운영시간 자동 판별은 포함하지 않는다.

### 동일 시각 디버깅 비교 (2026-10-09)

종목의 독립적인 최신 5봉 대신 시장의 최근 완료된 5개 5분봉 cntr_tm을 기준으로 종목 원본을 정확히 매칭한다. stock·market 배열의 길이와 시각 순서는 동일하다. 해당 시각 종목 봉이 없으면 그 시각은 유지하고 cur_prc/trde_qty를 null(UI는 -)로 표시한다. 시장 마감 이후 NXT 종목 봉은 비교 표에 포함하지 않는다. 시장 봉이 없으면 양쪽 모두 빈 배열이다. 이 규칙은 일반 차트 응답의 디버깅 필드와 디버깅 전용 요청에 동일하게 적용한다.


쏠림율은 모든 유효한 봉에 주황색 원형 표식을 가진 꺾은선으로 표시한다. 불러온 마지막 현재 봉이 표시 범위 안에 있으면 그 표식은 더 큰 파란색 원과 흰 테두리로 구분한다. 과거 범위의 마지막 봉을 현재 봉으로 표시하지 않는다.

## 쏠림율 아래 종목 캔들차트

종목 ka10080/ka10081 원본 open_pric·high_pric·low_pric·cur_prc의 절댓값을 stock_open·stock_high·stock_low·stock_price로 전달한다. 같은 봉 배열과 X좌표를 공유하는 캔들차트를 쏠림율 아래 기본 펼침 상태로 표시하며 버튼으로 접거나 펼친다. 시가보다 현재가가 높으면 붉은색, 낮으면 파란색, 같으면 회색이다. OHLC가 누락·무효이면 해당 위치는 유지하고 캔들을 그리지 않는다.

일봉·모든 분 간격·추가조회·확대·이동·자동갱신·계산 불가 분봉 제거가 두 차트에 동일하게 반영된다. 어느 차트에서 마우스를 이동해도 동일 봉의 날짜/시간·쏠림율·OHLC와 시가 대비 상승률((현재가/시가-1)×100)을 함께 표시하고 두 차트에 같은 세로 위치선을 표시한다. 시가가 없거나 0이면 상승률은 -다. 가격 축은 현재 표시 범위의 OHLC에 맞춰 조절하되 시간축은 쏠림율 차트와 정확히 공유한다. 서버 재시작 후 새 OHLC 필드를 받을 수 있다.

### 마우스 정보와 전일 대비 상승률

마우스 정보는 상단 차트 밖의 고정 높이 영역 한 곳에 표시해 두 그래프를 가리지 않는다. 날짜/시간 · 쏠림율 · 상승률 순으로 표시하고 OHLC 및 시가 대비 문구는 제거한다. 상승률은 (현재 봉 현재가 / 전일 종가 - 1) × 100이다.

원천 pred_pre 및 pred_pre_sig(1/2 상승, 4/5 하락, 3 보합)로 전일 종가를 복원하여 stock_previous_close·stock_change_rate를 반환한다. 전일 대비 기호가 없으면 명시적 부호가 있는 pred_pre 또는 0만 사용한다. 일봉은 전일 대비 필드가 없을 때 직전 거래일 봉 종가를 사용할 수 있다. 분봉은 직전 분봉 또는 당일 시가를 전일 종가로 대체하지 않는다. 기준을 확인할 수 없으면 상승률은 -다. 새 필드는 서버 재시작 후 적용된다.


캔들차트의 세로 날짜 구분선은 쏠림율에서 계산한 경계 X좌표를 그대로 공유한다. 분봉은 날짜 경계, 일봉은 월 경계이며 최소 32px 간격과 회색 점선 스타일을 동일하게 적용한다. 확대·이동·리사이즈 후에도 구분선 위치가 일치한다.


캔들차트 펼침/접음 버튼은 헤더의 과거 데이터 불러오기 버튼 바로 오른쪽에 12px 간격으로 배치한다. 두 버튼을 같은 그룹에 넣어 좁은 화면에서도 함께 배치한다.

### 차트 내부 여백에 마우스 정보 배치

고정 외부 정보 영역을 제거하고 기존 정보 색상을 유지한 채 두 차트 안에 정보를 표시한다. 선택 봉의 위·아래 공간을 비교해 여유가 큰 쪽 끝을 우선 선택한다. 정보 상자와 선분·표식 또는 캔들 고저가 영역의 충돌을 검사해 좌우 빈 위치를 찾는다. 우선 방향에 빈 위치가 없으면 반대 방향을 확인하고, 모든 위치가 겹치는 경우 겹침이 가장 적은 위치를 사용한다. 상자는 차트 가로 경계를 넘지 않고 마우스 이벤트를 가로막지 않는다. 날짜/시간·쏠림율·전일 대비 상승률 내용은 유지한다.


두 차트 모두 포인터 드래그 확대/전체 복원을 지원한다. 어느 차트에서 시작해도 드래그 진행 영역의 X좌표·폭·방향별 색상을 두 차트에 동일하게 표시한다. 공유 표시 범위를 변경하므로 종료 후 확대/복원 결과도 동일하다. 포인터 캡처·취소 처리는 드래그를 시작한 캔버스에 귀속하며 조회를 추가로 발생시키지 않는다.


디버깅 표 오른쪽에 최근 5봉 각각의 계산 거래대금(원)을 표시한다. 종목은 abs(cur_prc)×trde_qty, 시장은 사용자 지정 추정식 (abs(cur_prc)/100)×(trde_qty×10000)이다. 쉼표로 자릿수를 구분하고 원본 필드가 누락·무효이면 -로 표시한다. 시장 값은 실제 거래대금이 아닌 기존 추정식 결과다. 비교 표 폭은 430px, 데스크톱 패널은 기존 절반 폭에 450px를 추가한다.


현재 쏠림율 숫자는 상단 헤더 대신 쏠림율 세로축 위에 표시하며 쏠림율 제목 글자는 제거한다. 디버깅은 세로축 중앙의 텍스트 없는 화살표 버튼으로 펼치거나 접는다. 버튼은 접근 가능한 이름과 펼침 상태를 제공한다. 접으면 패널 폭을 원래 절반 폭으로 복원하며 기존 디버깅 값·차트 선택·표시 구간을 보존한다.

### Rank 차트 펼침 상태 저장

사용자 설정 스냅샷에 rankChartDisplay={debugOpen:boolean,candleOpen:boolean}를 포함한다. 둘의 기본값은 false이며 필드가 없는 예전 설정도 닫힘으로 복원한다. 버튼 변경은 기존 saveAppData 경로로 로컬 설정과 user_settings_autosaved.json에 저장한다. 전체 설정 다운로드 및 user_settings_manualsaved/full_backup 수동 백업도 같은 스냅샷 필드를 포함한다. 기존 설정 파일·과거 백업을 직접 덮어써서 마이그레이션하지 않는다.

시작 시 서버/로컬 설정 적용과 수동 백업 복원 모두 동일한 상태 적용 함수를 사용한다. 복원 자체는 토글 클릭이나 별도 자동 저장을 발생시키지 않는다. 값은 엄격한 boolean true만 펼침으로 처리한다. 저장 실패 처리는 기존 설정 동기화 정책을 따른다.


현재 쏠림율 숫자는 캔들 펼침 버튼과 같은 헤더 가로줄에 배치해 축 위 별도 높이를 없앤다. 디버깅 펼침 버튼은 세로축보다 오른쪽인 차트 영역 맨 오른쪽 끝에 붙이고 세로 중앙을 유지한다. 축 숫자는 버튼과 겹치지 않도록 오른쪽 여백을 확보한다.


줌 슬라이더·± 버튼 및 기간 표시를 디버깅 영역과 분리된 차트 열 안에 배치한다. 디버깅 펼침으로 패널 전체가 넓어져도 줌 조절 영역은 차트 열의 폭을 유지한다. 데스크톱 추가 450px는 디버깅 434px와 열 간격 16px로 맞추며 휴대폰에서는 줌 영역이 캔들차트 아래, 디버깅 표 위에 위치한다.


캔들 버튼의 표시 글자는 캔들차트만 사용하며 펼침/접음은 접근 가능한 이름과 aria-expanded로 제공한다. 디버깅을 접었을 때 차트 패널 폭은 거래대금 상위 패널의 실제 폭과 맞춰 내부 차트 폭이 테이블 폭과 같도록 한다. ResizeObserver로 표 패널 폭 변경을 반영하고 모바일 화면 폭 제한을 유지한다. 디버깅 펼침은 이 기준 폭에 450px를 추가한다.


일·분 선택 버튼은 종목 입력 아래 분봉 간격 버튼과 동일한 가로줄에 배치한다. 두 그룹이 서로 다른 줄로 나뉘지 않도록 공통 행으로 묶는다.


일·분, 분 간격, 추가조회, 캔들 버튼 및 현재 쏠림율을 같은 공통 행으로 묶는다. 버튼 폭과 간격을 조절해 데스크톱 차트 폭 안에 배치하며 매우 좁은 화면에서는 같은 행을 가로 스크롤한다.

### 봉 종류와 간격 저장

차트 기본 봉 종류는 day(일봉), 기본 분 간격은 1이다. 기존 rankChartDisplay 설정에 mode(day/minute)와 interval(1·3·5·10·15·30·45·60)을 추가한다. 일·분 및 분 간격 변경은 기존 사용자 설정 자동 저장과 수동 백업에 포함된다. 시작/설정 불러오기/전체 백업 복원 시 선택 버튼과 차트에 적용한다. 필드가 없거나 무효이면 일봉·1분으로 처리한다. 일봉에서도 마지막 분 간격을 보존하고 분봉 전환 시 적용한다.

## 2026-10-21 현재값 기준 날짜

쏠림율과 ADR은 현재값 바로 위에 마지막 값의 기준 날짜(YYYY-MM-DD)를 표시한다. 날짜는 절대 위치로 배치해 현재값·버튼·그래프를 아래로 밀지 않는다. ADR의 메인 캔버스도 쏠림율과 같은 260px이며 내부 그래프 여백은 위 10px·아래 34px다. `node dev/tests/chart-value-dates.test.cjs`는 실제 전체 페이지에서 두 캔버스의 높이와 날짜 숨김 전후의 현재값·캔버스 좌표가 같은지 측정한다.


## 2026-10-21 그래프 시작선 검증

쏠림율·수급·신고가·거래대금·변동성·CNN·ADR 모두 일봉은 월이 바뀌는 첫 봉, 분봉은 거래일이 바뀌는 첫 봉에 회색 세로 점선을 표시한다. 경계 사이 최소 32px를 확보하고 메인 그래프에서 계산한 X좌표를 아래 캔들차트에도 공유한다. 확대·이동·크기 변경 시 다시 계산한다. 당일만 있는 분봉에는 거래일 경계선이 나타나지 않는다.

## 쏠림율 분봉 조회 진행 판단 보완 (2026-10-25)

사용자 화면에서 종목수급 삼성전자 과거 가격은 있지만 키움 쏠림율은 900봉만 표시되고, 한투는 거래건수 초과로 지표가 결측인 상황을 확인했다. 공통 추가조회가 키움의 고정 UUID 커서와 종목 시작일만 비교하면, 한 요청에서 종목 범위는 그대로이고 업종 거래대금 페이지만 전진하는 경우를 진행 없음으로 오판할 수 있다. 서버 응답에 stock/index 행 수·최초 시각의 history_progress를 추가하고 프론트/공통 loader가 이를 함께 비교하도록 했다. 커서가 같아도 업종 범위가 전진하면 필요한 다음 페이지를 계속 조회한다. 한투 partial 또는 요청 실패는 loader error로 전달하여 범위 확보 성공으로 처리하지 않는다. 한투 카드의 더 불러오기 버튼도 공통 상태 갱신 대상에 포함했다.

KIS 공통 대기열 완료 후 간격은 모든 /uapi/ 요청에 550ms로 통일했다. 이전 일반 도메인 150ms 설명을 대체한다. 동 계정의 외부 프로그램은 제어하지 못하므로 실제 제한 해소를 보장하지 않는다.

로컬 업종 분봉 저장소 확인 시 `data/kis-concentration/0001/20261023.json`만 존재했다. 이 사실은 가격 봉이 10/19부터 존재하는 것과 별개이며, 미수집 과거 한투 업종 누적 거래대금 없이는 해당 날짜의 한투 쏠림율을 만들 수 없다. 키움 값이나 가격으로 대체하지 않는다. 실제 API 회복/추가 수집 결과는 별도 확인한다.

검증: 고정 커서로 업종만 2회 전진 후 종목 과거 확장하는 회귀를 포함한 Node 35개 및 Chrome 한투 부분 실패 캔들 유지·정상 복구 테스트 통과. 사용자 실제 가격/분모 추가조회는 서버 재시작 후 재확인이 필요하다.

## 다른 카드의 선택 변경 후 기간 점검 (2026-10-25)

종목수급과 같은 최신 페이지만 다시 조회하는 경로가 쏠림율(키움/한투) 종목 선택, 시장수급·ADR·신고 시장 선택에도 있어 보완했다. RankChartAxis.restoreHistoryRange는 현재 공통 시작 시점을 목표로 변경된 카드만 필요한 페이지를 추격하며 다른 카드의 과거 범위를 더 확장하지 않는다. 고정 커서의 progress, 실제 기준 페이지의 coverageFirst, 선택 identity와 busy/error를 함께 확인한다. 가격이 합쳐져 시간축만 길어졌다고 지표 기준 페이지도 확보한 것으로 오판하지 않는다.

쏠림율은 새 종목의 최초 조회가 완료된 뒤 공통 기간까지 추가 조회한다. 시장수급 분봉은 공통 기간의 날짜별 저장 수급과 응답 캔들을 다시 병합하고 선택 시장의 가격 보강을 완료한다. ADR·신고는 새 시장의 기준/지표 페이지를 추가 조회한 뒤 목표 가격 기간도 보강한다. 원천 과거 자료가 끝난 경우 지표는 결측으로 남기되 가능한 가격 보강은 수행한다. 선택이나 주기가 바뀌면 이전 복원 작업은 현재 선택을 덮지 않으며 실패는 해당 카드 안내로 남긴다.

거래대금은 원래 KOSPI/KOSDAQ 자료를 모두 보관하고 표시 선택만 바꾸므로 해당 최신 페이지 초기화 문제가 없다. 변동성·투자심리는 종목/시장 선택 자체가 없다. 한투 API 제한이나 미수집 한투 업종 금액처럼 실제 원천이 없는 문제까지 해결된 것으로 해석하지 않는다.

검증: 선택 카드만 여러 페이지로 공통 기간 추격·다른 카드 추가조회 없음·자료 끝에도 가격 ensure 실행을 포함한 목표 회귀 9개, Chrome 시장 라디오/캔들 회귀 및 종목수급 5일 왕복 회귀 통과. 실제 운영 선택 변경은 별도 확인한다.
