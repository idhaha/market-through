# 키움 시장 수급과 비교 배치

트레이딩 탭 마지막 두 줄은 다음 순서다. 데스크톱 3열 기준으로 종목 수급 3개가 위쪽, 시장 수급 3개가 아래쪽이다. 작은 화면은 같은 순서를 유지하며 한 열로 표시한다.

- 종목 수급(키움), 종목 수급(한투), 종목 수급(LS)
- 시장 수급(키움), 시장 수급(한투), 시장 수급(LS)

기존 종목·시장 렌더러를 재사용한다. 시간축·당일·과거 조회·확대/축소·캔들 동기화·실제 0/결측 구분·연결 표시·카드별 선택 설정 정책은 공통이다. 시장 수급의 세 카드 모두 레이블·툴팁·수급 축을 억원으로 표시한다. 내부 저장 단위는 기존과 같은 백만원이다. LS 일봉은 종전처럼 한투 소스를 사용하며 카드 출처 표시에 명시한다.

## 키움 소스

- 개인·외국인·기관: REST `ka10051` 업종별투자자순매수요청. `/api/dostk/sect`, 금액 `amt_qty_tp=0`, `stex_tp=3` 통합. 시장 구분은 코스피 0, 코스닥 1이다. 종합 행 `001_AL` / `101_AL`의 `ind_netprps`, `frgnr_netprps`, `orgn_netprps`만 사용한다. 업종 행을 합산하지 않는다. 원본 억원에 100을 곱해 백만원으로 저장한다.
- 프로그램 분봉: REST `ka90005`, `/api/dostk/mrkcond`, 금액 `amt_qty_tp=1`, 분 `min_tic_tp=1`, `stex_tp=3`. 시장 키는 코스피 `P001_AL01`, 코스닥 `P101_AL02`. `all_netprps`는 원본 백만원 그대로 사용한다. `--681513` 같은 이중 표시 부호도 기존 수량 파서로 음수로 해석한다.
- 프로그램 일봉: REST `ka90010`, 같은 시장 키·단위, `cntr_tm`의 일자와 `all_netprps`를 사용한다. 연속조회 키를 따라 가격 봉 범위를 채운다.

웹소켓은 사용하지 않는다. 키움에서 확인된 현물 두 시장만 선택할 수 있다. 한투·LS의 선물 선택은 유지한다.

## 수집·저장

기존 공통 개장 확인을 통과한 날, 08:00~20:01에 서버에서 분당 한 번 수집한다. 투자자는 REST 관측 분의 누적값만 저장하며 과거 투자자 분봉을 만들지 않는다. 현재 분은 보류하고 완료된 분부터 표시한다. 프로그램은 REST가 제공하는 원천 분 시각으로 기록하며 현재/미래 분은 제외한다. 이미 같은 원천 시각·값이 저장된 분은 다시 쓰지 않는다. 실패한 소스는 결측으로 남기고 다른 소스의 저장을 계속한다.

분봉은 `data/kiwoom-market-supply/`에 별도 저장하며 완료 일자는 기존 저장소의 무손실 압축 정책을 사용한다. 일봉은 영속 저장하지 않고 공통 일봉 부분 응답·과거 캐시를 사용한다. 최근 두 날짜를 갱신하고 과거 범위는 재사용한다. 가격 캔들은 기존 키움 시장 지수 경로를 공유한다. 적용에는 서버 재시작이 필요하다.

## 검증

2026-10-26 공식 API 실제 호출에서 두 시장 모두 `ka10051`, `ka90005`, `ka90010` 응답 코드 0 및 통합 종합 행/시장 키를 확인했다. 코스피 투자자는 개인 +1,225억원, 외인 -7,599억원, 기관 +5,931억원이었다. 프로그램 분봉의 원천 시각 17:27 값은 -681,513백만원이었다. 값은 조회 당시 스냅샷이며, 서로 다른 증권사의 같은 시각 대조를 완료했다는 뜻은 아니다. 키·토큰을 제외한 근거는 `dev/output/kiwoom-market-probe.json`에 기록했다. 서버 재시작 없이 읽기 전용 조회만 실행했다.

자동 검증: `dev/tests/kiwoom-market-supply.test.cjs`, `dev/tests/market-supply-service.test.cjs`, `dev/tests/rank-market-supply-page.test.cjs`에서 배율·종합 행 선택·0/결측·완료 분·연속조회·원천별 실패 격리·부분 응답과 마지막 두 줄 배치를 확인한다.
