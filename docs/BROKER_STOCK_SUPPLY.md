# 종목 수급 비교 카드

트레이딩 탭 마지막에 `종목 수급(한투)`, `종목 수급(LS)` 테스트 카드를 둔다. `rank-supply-chart.js`의 기존 키움 렌더러를 함께 사용한다. 종목 목록은 기존 최대 5개 목록을 공유하며 선택 종목·일/분봉·표시 주체는 카드별로 유지한다. 공통 축·과거 조회·캔들 동기화·결측/실제 0 처리·주/천주 레이블 정책을 재사용한다. 기존 독립창의 구성에는 테스트 카드를 추가하지 않는다.

## 원천

- 한투 일봉 투자자: `FHKST01010900`, `inquire-investor`, 시장 J(KRX). 제공되는 최근 기간만 표시한다. 당일은 장중 일봉 투자자 값으로 사용하지 않는다.
- 한투 분봉 투자자: `HHPTJ04160200`, `investor-trend-estimate`. 외국인·기관의 비정기 가집계를 REST 관측 분에 저장한다. 개인은 미제공이다. 입력구분은 갱신 순서이며 원천 시각으로 취급하지 않는다.
- 한투 일봉 프로그램: `FHPPG04650201`, `program-trade-by-stock-daily`, UN(통합), `whol_smtn_ntby_qty`.
- 한투 분봉 프로그램: 웹소켓 `H0UNPGM0`, 통합, `NTBY_CNQN`(11개 필드 중 인덱스 6).
- LS 일/분봉 투자자: `t1717`, `/stock/frgr-itt`, 일간 순매수·U(통합), `tjj0008_vol` 개인 / `tjj0016_vol` 외인계 / `tjj0018_vol` 기관. 실시간 정보가 아닌 추정치이며 분봉은 REST 관측 분이다.
- LS 일봉 프로그램: `t1637`, 수량·일자·U, `svolume`.
- LS 분봉 프로그램: 웹소켓 `UPH`, `U`+6자리 종목코드+공백 3자리 키, `tvol`.

모두 순매수 **수량(주)** 이다. 프로그램 금액 필드와 시장 수급 카드의 억원/백만원 배율은 사용하지 않는다. 가격 캔들만 기존 키움 공통 경로를 이용한다. 타사 수급으로 빈 값을 보완하지 않는다. 일봉 소스는 메모리 캐시와 부분 응답을 사용하며 가격·투자자·프로그램이 도착하는 대로 표시한다.

## 수집

서버당 증권사별 한 연결에서 지정 종목을 구독한다. 브라우저 수와 무관하다. 프로그램은 계속 수신하되 원천 시각 기준 분당 마지막 값을 저장하고 완료된 분부터 표시한다. 2분 이상 지연·미래·역순·다른 종목·다른 시장 메시지를 제외한다. 구독 승인과 실제 수신을 구별한다. 재연결은 지수 지연을 사용하며 종목 변경 시 구독 해제/추가한다. 투자자는 분당 최대 한 번, 종목별 순차 REST 호출이며 기존 개장 확인과 수집 시간 정책을 따른다. 완료된 일자는 기존 저장소의 무손실 압축을 사용한다.

`data/kis-supply/`, `data/ls-supply/`는 별도 분봉 저장소다. 기존 분봉을 복사하거나 소급 생성하지 않는다. 설정을 변경해도 기존 키움의 저장 자료를 수정하지 않는다. 새 백엔드 적용에는 서버 재시작이 필요하다.

## 확인 기록 (2026-10-26)

삼성전자 005930 실제 REST 응답에서 오늘 개인 357,058주·외인 -1,002,291주·기관 612,382주가 한투/LS에서 동일했다. 통합 프로그램은 양쪽 모두 -1,151,276주였다. KRX 투자자와 통합 투자자의 과거 일자는 시장 범위 차이로 값이 다를 수 있다. 이 대조를 모든 시점·모든 시장의 일치로 확대하지 않는다.

두 웹소켓에서 구독 승인을 확인했다. 16시대 각 15초 검증 중 실제 프로그램 메시지는 수신하지 못했으므로 실거래 메시지부터 파일 저장·화면 표시까지의 운영 확인은 미완료다. 서버는 이 검증으로 재시작하지 않았다. 개발 프로브 결과는 `dev/output/broker-stock-probe.json`에 저장했다(키·토큰 제외).

자동 검증은 `dev/tests/broker-stock-supply.test.cjs`와 `dev/tests/rank-market-supply-page.test.cjs`에서 수량 필드, 완료 분·0·역순/결측 구분, 종목 구독 변경과 재연결, 원천 분리, 카드 순서·설정 격리를 확인한다.

공식 문서: [LS API 가이드](https://openapi.ls-sec.co.kr/apiservice), [한투 공식 예제](https://github.com/koreainvestment/open-trading-api/tree/main/examples_llm/domestic_stock), [한투 웹소켓 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_user/domestic_stock/domestic_stock_functions_ws.py).


## 2026-10-26 종목 일봉 과거 조회 보완

한투 투자자 일봉은 최근 구간만 반환하는 FHKST01010900 대신 날짜 지정 FHPTJ04160001(`/investor-trade-by-stock-daily`, KRX J)의 output2를 사용한다. 응답 최저 날짜 전날로 이동한다. LS t1717은 250일 응답 이후 종료일을 과거로 이동한다. LS t1637은 마지막 행 날짜와 응답 연속조회 키·Y 헤더를 함께 전달한다. 프로그램 12페이지 상한은 80페이지로 늘렸으며 상한·실패는 경고로 표시한다.

투자자·프로그램을 각각 6시간 메모리 이력 캐시에 보관하고 최근 두 거래일만 갱신한다. 일봉 영구 저장 정책은 변경하지 않는다. 장중 한투 당일 투자자 일봉 제외 정책과 LS 투자자 추정치 안내도 유지한다.

실제 삼성전자 600봉(2024-05-07~2026-10-26)에서 한투·LS의 개인·외국인·기관·프로그램 모두 600개 유효값을 확인했다. 첫 전체 조회 실측은 한투 약15.5초, LS 약49초였으며 호출 제한 대기와 당일 원천 응답에 따라 달라진다. 결과는 로컬 dev/output/stock-history-full-validation.json에 기록한다. 상주 수집기 추가·운영 서버 재시작은 하지 않았다.

2026-10-27 장중 확인: 삼성전자/하이닉스 t1717 통합 당일 행은 투자자 수량 및 단가 필드가 모두0으로 반환됐고 전일 행은 유효한 비영값이었다. 원천 응답만으로 당일 실제 순매수0과 미집계0을 구분할 수 없어 실제 체결 수급0으로 확정하지 않는다. 한투 삼성전자 분봉 저장에는 외국인/기관 가집계가 존재했고 개인은 미제공이다. 세부 근거는 비공개 dev/output/ls-stock-investor-probe.json 및 supply-runtime-compare.json에 있다.

2026-10-27 한투 시장수급 선물 일봉 검토: 공식 포털 /apiservice-apiservice?/uapi/domestic-stock/v1/quotations/inquire-investor-daily-by-market (FHPTJ04040000)의 FID_INPUT_ISCD_1 지원 설명은 KSP/KSQ이고 두 업종코드 필드도 코스피/코스닥 업종분류코드다. 20261026/20261027 실응답에서 현물 KSP/0001은 각각300행, 선물 K2I/F001 및 KQI/F002는 모두 정상처리 빈 배열이었다. 일봉 선물 제공이 확인되지 않아 키움·한투 카드에 선물 일봉 선택을 추가하지 않았다. 기존 분봉 선택은 유지. 근거는 dev/output/kis-futures-daily-probe.json 및 kis-official-api-page.txt.
