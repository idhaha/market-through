# Rank 공통 차트 정책

최종 기준: 2026-10-21, 한국 시간. 이 문서는 해당 대화의 최종 결정을 정리한 현재 정책이다. 다른 문서의 과거 배치·레이블·높이·캔들 개별 조작 설명과 충돌하면 이 문서를 우선한다. 데이터 수집은 [신고가·신저가](BREADTH_CHART.md), [수급](SUPPLY_CHART.md), [쏠림율](CONCENTRATION_CHART.md)을 함께 참고한다.

## 메인 배치

- 첫 줄: 쏠림율 / 수급 / 신고가·신저가.
- 둘째 줄: 거래대금 / 변동성 / CNN Fear & Greed·하이일드 스프레드.
- ADR: 셋째 줄 왼쪽. 신고가·신저가와 거래대금은 이전 위치에서 서로 교환했다.
- 독립창은 기존 거래대금 순위·쏠림율·수급의 세로 배치를 유지한다.

## 그래프 높이와 시작선

- 7개 메인 차트 모두 실제 메인 캔버스 높이 260px를 사용한다. 내부 그래프 여백은 위 10px·아래 34px로 통일한다.
- 높이만 같게 하는 것으로 끝내지 않고, 카드 상단부터 캔버스 시작까지 거리도 맞춘다. 제목 줄 36px, 버튼 줄 40px, 외부 마우스 정보 줄 20px를 기준으로 한다.
- 기본 데스크톱 전체 페이지의 브라우저 검증에서 7개 카드 모두 캔버스 시작 오프셋 127px·캔버스 높이 260px를 확인했다. 127px는 현재 기본 레이아웃의 측정값이며 임의 화면 배율에서 고정 좌표로 사용하지 않는다.
- 두 줄 레이블은 행당 18px, 행 사이 2px로 버튼 줄 안에 배치한다. 날짜 추가나 큰 글꼴 때문에 버튼 줄·그래프가 아래로 밀리면 안 된다.
- 거래대금의 기간·캔들 버튼은 기본 카드 폭에서도 한 줄에 들어가도록 간격을 조정한다. 아래 캔들 영역은 메인 그래프와 별도다.

## 레이블과 기준 날짜

- 거래대금: KOSPI·KOSDAQ 두 행. 시장명 시작점은 왼쪽 정렬, 금액은 오른쪽 정렬한다. 두 행 위에 실제 마지막 유효 값의 날짜를 표시한다. 시장별 날짜가 다르면 시장별 날짜를 구분한다.
- 신고가·신저가: 두 행, 신고가 빨강·신저가 파랑으로 그래프와 같은 색을 사용한다. 위에 표시 값의 기준 날짜를 표시한다. 마지막 기준 봉이 결측이면 값·날짜를 만들어 채우지 않는다.
- 변동성: VKOSPI·VIX 두 행을 각 그래프 색으로 표시하고 위에 마지막 값의 날짜를 둔다. 날짜가 다르면 지표별로 구분한다.
- CNN·하이일드: 두 행을 각 그래프 색으로 표시한다. 공통 날짜 한 줄 대신 각 지표의 날짜를 해당 레이블 왼쪽에 표시한다.
- 쏠림율·ADR: 현재값 바로 위에 기준 날짜를 표시한다. 쏠림율 날짜는 버튼 줄의 가로 스크롤 영역 밖에 두어 위쪽이 잘리지 않게 한다.
- 수급: 이름 12px·수치 13px, 개/외/기/프 두 행을 버튼 줄 오른쪽에 둔다. 위에 각 주체의 마지막 유효 관측 날짜를 표시하고, 날짜가 다르면 가장 이른 날짜~가장 늦은 날짜 범위를 표시한다. 개별 값의 마우스오버에는 정확한 기준 시각을 유지한다.
- 날짜 형식은 YYYY-MM-DD다. 레이블 위 날짜는 절대 위치로 배치해 값·버튼·캔버스 위치와 높이에 영향을 주지 않는다.
- 수급의 절댓값이 1,000주 이상이면 1,000으로 나눈 뒤 소수 부분을 0 방향으로 버리고 천주로 표시한다. 예: 12,345주→12천주, -12,345주→-12천주, 999주→999주. 원본 저장·계산값은 바꾸지 않고 레이블·마우스 정보·수급 세로축 표시만 바꾼다. 가격 캔들 축에는 적용하지 않는다.

## 신고가 전환 안내

카드 우측 상단에 다음 두 줄을 표시한다. 설명 묶음의 오른쪽 끝은 세로축 레이블의 오른쪽 끝에 맞추고 두 줄끼리는 왼쪽 정렬한다. 문구를 기존 제목 줄보다 6px 위로 올리며 그래프 위치를 바꾸지 않는다.

```text
2026-10-20까지 KOSPI
2026-10-21부터 KOSPI+KOSDAQ(KRX+NXT 통합)
```

## 캔들 버튼

- 메인창에서 어느 차트의 캔들 버튼을 눌러도 7개 차트를 모두 같은 상태로 펼치거나 접는다. 차트별 로딩·높이·aria-expanded 처리를 재사용하고 완료된 상태를 한 번 저장한다.
- 독립창은 동기화 대상에서 제외한다. 독립창의 차트별 캔들 조작과 창별 펼침 상태는 유지한다.
- 이 변경은 버튼 조작에 적용한다. 기존 개별 상태가 담긴 설정을 읽는 것 자체를 사용자 클릭으로 취급하거나 설정 파일을 강제로 덮어쓰지 않는다.

## 날짜 경계의 세로 점선

- 일봉: 월이 바뀌는 첫 봉. 분봉: 거래일이 바뀌는 첫 봉.
- 회색 점선, 최소 32px 간격. 더 좁은 경계는 생략하고 확대·이동·리사이즈 후 다시 계산한다.
- 메인 그래프의 경계 X좌표를 아래 캔들에도 공유한다. 당일 분봉만 있으면 거래일 경계선은 없다.
- 거래일을 같은 봉 간격으로 그리는 차트는 월별 거래일 수에 따라 월 경계 사이 폭이 달라진다. 주말·휴장일을 가짜 봉으로 채우지 않는다.

## 적용과 검증

- 서버 수집 코드 변경은 서버 재시작이 필요하다. 화면 JS/CSS 변경은 브라우저 새로고침으로 적용한다. 포트 3000이 이미 점유되어 있으면 실행 중인 서버를 확인하고 해당 프로세스를 재시작한다.
- 로컬 모의 API/Edge 브라우저 검증은 Oracle 배포·운영 데이터 검증을 의미하지 않는다. 다음날 새벽 ka10016 목록 유지 여부는 별도 운영 확인 대상이다.
- 이번 대화에서 실행·통과한 관련 검증: `breadth-service.test.cjs`, `supply-service.test.cjs`, `risk-volatility.test.cjs`, `rank-supply.test.cjs`, `rank-volatility.test.cjs`, `rank-turnover.test.cjs`, `chart-value-dates.test.cjs`.
- `chart-value-dates.test.cjs`는 전체 페이지에서 7개 차트의 시작선·높이, 날짜 표시 전후 값·캔버스 위치, 메인 캔들 동시 펼침·접힘과 독립 모드 제외를 확인한다.
