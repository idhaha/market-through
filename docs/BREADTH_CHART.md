# 신고가·신저가 차트

2026-10-21 최종 정책. 이전 신고가·신저가의 Jusikbot 조회·기간 선택 설명보다 이 문서를 우선한다. 레이블·날짜·배치·높이·캔들 동기화·세로 점선은 [공통 차트 정책](RANK_CHART_POLICY.md)을 따른다.

## 집계와 보관

- 기존 `data/volatility/new-highs-lows.json`의 원본 바이트를 최초 실행 시 `data/breadth/jusikbot-backup.json`으로 백업하고 일별 개수를 `daily.json`에 이관한다. 원본은 유지한다. 이후 이 차트는 Jusikbot을 조회하지 않는다.
- `ka10016`, `/api/dostk/stkinfo`에서 KOSPI(001), KOSDAQ(101)의 신고가(1)와 신저가(2)를 각각 조회한다. 통합 거래소 3, 고저 기준 1, 기간 250일, 종목·거래량·신용 제한 없음, 상하한 포함이다. 각 목록의 전체 페이지를 완료하고 거래소 접미사를 제거한 종목코드로 중복을 제거한다. 한 종목이 양쪽에 있으면 양쪽에서 한 번씩 센다.
- 일별 자료는 날짜·신고가 수·신저가 수만 저장한다. 출처·조건은 날짜별로 기록하지 않는다. 파일 전체에 과거자료 마지막 날짜와 통합 집계 시작일을 두고 카드 우측 상단에 두 줄로 표시한다. 첫 줄은 `…까지 KOSPI`, 둘째 줄은 `…부터 KOSPI+KOSDAQ(KRX+NXT 통합)`이다. 설명 묶음의 오른쪽 끝은 세로축 레이블 우측 끝에 맞추고, 묶음 안 두 줄은 왼쪽 정렬한다. 제목 줄에서 6px 위로 올리고 줄을 추가해 그래프를 밀지 않는다.
- 수급 서비스의 개장 확인과 `data/supply/market-day.json`을 공유한다. 평일 한국 시간 08:00~10:30(포함), 분당 최대 한 번 삼성전자 005930_AL의 당일·현재시각 이하·양수 거래량 분봉으로 확인한다. 신고가 차트 수집은 수급 등록 종목이 없어도 확인을 수행한다. 동시 확인은 하나의 요청을 공유한다.
- 당일 확인 기록이 없는 10:30 이후 첫 실행은 수집하지 않는다. 확인 후 VI 등으로 거래가 중단되어도 수집을 유지한다. 날짜가 바뀌면 새 확인이 필요하다.
- 확인 직후부터 20:01까지 60초마다 목록 개수를 관측한다. 1분봉은 신규 발생 개수가 아닌 해당 시점 전체 목록 개수다. 브라우저 접속 여부와 무관하다. 양쪽 전체 페이지 성공 시에만 저장한다. 같은 분은 최신 정상 관측값 하나를 유지한다.
- `data/breadth/YYYY-MM-DD.json`에 분봉을 보관하고 20:02 이후 gzip으로 압축한다. 원본 바이트 일치 검증 후 JSON을 제거한다. 재시작 시 지난 날짜도 압축한다. 자동 삭제하지 않는다.
- 개장 확인된 날 20:02부터 일봉 최종 집계를 시도한다. 다음날 08:00 미만까지 재시작·1분 주기 점검에서 재시도한다. 전일 개장 확인 기록을 요구하며 기준 분봉의 최신 거래일을 조회 전후로 확인한다. 날짜가 바뀌거나 복구 기한을 지나면 저장하지 않는다. 최종 확정은 날짜당 한 번이다.
- `ka10016`에는 과거 기준일 입력이 없다. 다음날 새벽 목록이 전일 최종 상태를 유지하는지는 실제 운영 검증이 필요하다. 기준 분봉 날짜 확인은 다른 거래일로의 잘못된 저장을 방지하지만 원천 목록의 갱신 시점을 직접 증명하지는 않는다.
- 조회 실패는 결측이며 정상 빈 목록은 0이다. 수집 이전·서버 중단 구간을 소급 생성하거나 마지막 분봉으로 일봉을 대체하지 않는다. 서버 단일 인스턴스 운용을 전제로 한다.

## 조회와 화면

- 메인 데스크톱 배치는 신고가·신저가가 첫 줄 오른쪽(3열), 거래대금이 둘째 줄 왼쪽(1열)이다. 두 카드의 이전 위치를 맞바꾼다.
- 인증된 `GET /api/risk/breadth?mode=day|minute&cursor=…`. 기본은 day. `dates`, `series.highs/lows.points`, `candles`, `cursor`, `has_more`, `notice`, `warning`을 반환한다. 신저가 표시값만 음수다. 결측값은 null이다.
- 삼성전자 통합시장 `ka10081`/`ka10080` 기본 한 페이지를 기준 시간축으로 사용한다. 신고가 자료 유무와 관계없이 쏠림율 기본 페이지와 같은 봉 수 정책을 따른다. 표시 캔들은 기존 KOSPI 지수를 유지하며 기준 시간축에 맞춘다. KRX 지수가 없는 NXT 시간대는 캔들만 결측으로 둔다.
- 일/1분봉, 과거 추가조회, 캔들 접기·펼치기, 확대·축소·드래그·슬라이더·공유 커서를 제공한다. 캔들을 접어도 기준 시간축을 조회한다. 일봉은 이전 기준일, 분봉은 원천 연속조회 키로 과거 페이지를 추가한다.
- 최초·추가조회 성공 후 전체 로드 구간을 표시한다. 자동 갱신은 이미 읽은 구간과 줌·이동 위치를 유지한다. 일/1분봉과 캔들 상태는 사용자 설정에 저장한다.
- 신고가 빨강 양수·신저가 파랑 음수 막대, 단위는 개다. 결측 자리에는 막대를 그리지 않고 마우스 정보와 최신값은 —로 표시한다. 정상 0과 구분한다. 신고가·신저가 레이블도 그래프 색상의 두 행으로 표시하고 위에 기준 날짜를 둔다. 메인 캔버스 260px와 다른 카드와 동일한 시작선을 유지한다.

## 전환과 일회성 수동 집계 기록

- 실제 이관 자료: 2026-10-20까지 340거래일. 원본 백업을 보존했다.
- 사용자 요청으로 2026-10-21만 개장 확인 기록 요구를 예외 처리해 일회성 수동 조회·저장했다. KOSPI+KOSDAQ, KRX+NXT 통합, 신고가 46개·신저가 131개이며 저장된 일봉은 총 341거래일이 되었다.
- 수동 조회 전후 삼성전자 통합시장 최신 분봉은 모두 `20261021195900`이었다. 저장 전 `before-manual-20261021-<timestamp>.json` 백업을 생성했다.
- 이 예외를 서버 스케줄·개장 확인 정책에 넣지 않았다. 오늘 일봉만 추가했으며 과거 1분봉이나 개장 확인 기록을 만들지 않았다. 해당 일회성 스크립트는 Git에서 제외한 `dev/output/manual-breadth-20261021.cjs`다.
- 실제 안내 전환일은 2026-10-20까지 KOSPI, 2026-10-21부터 KOSPI+KOSDAQ(KRX+NXT 통합)이다. 날짜별 출처·집계 조건을 추가 저장하지 않는다.
