- NH 수량은 HTS의 증권금융 가능수량과 크기가 같은 수준이다. 그래서 같은 증권금융 유통대주 물량으로 보인다. 다만 시각이 달라 정확히 같은 값인지는 확정하지 못했다.

## 4. 제안 (승인 후 구현)

- 표 구성:
  - 목록과 현재가·등락률은 키움 ka10030(crd_tp 8)에서 받는다.
  - 수량은 같은 종목코드의 NH 유통대주 사용가능수량을 붙인다. NH에 없는 종목은 수량을 "-"로 표시한다.
  - 매매가능금액은 수량 × 현재가로 계산한다.
- 시간: 키움 7회 + NH 5회로 약 5초다. 현재 한투 방식은 276회 호출에 약 83초가 걸린다.
- NH 토큰: 새로 발급할 때마다 NH 보안 알림이 간다. 서버는 `data/nh-plug/token.json`을 재사용하고, 만료 시에만 발급해야 한다. 토큰은 하루 유효다.
- 한투 방식은 대체 원천이 실패했을 때의 예비로 남길지 정한다.
