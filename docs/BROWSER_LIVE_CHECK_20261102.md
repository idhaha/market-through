# 월요일 로컬 브라우저 점검

2026-11-02 한국시간 07:55~10:15, 17:55~22:00에 로컬 서버의 실제 브라우저 동작을 관찰한다. 오라클에 브라우저가 열려 있어도 오라클은 점검하지 않는다. 브라우저 코드와 수신 경로 모두 localhost·127.0.0.1·[::1]에서만 동작한다.

기존 API의 호출 경로·응답 상태·소요 시간, 카드 데이터 개수·마지막 시각, 캔버스 축소 이미지의 체크섬, 브라우저 오류 개수, 서버 대체 갱신의 중지 여부를 분당 기록한다. 증권사 조회나 차트 갱신을 추가로 실행하지 않고 사용자 설정을 변경하지 않는다. 응답 본문·종목명·이메일·인증정보는 기록하지 않는다.

로컬 서버 재시작과 브라우저 Ctrl+F5 후 사용한다. 평소 사용하던 자동갱신을 켜 둬야 자동갱신 동작을 관찰할 수 있다. 해당 날짜 22시 이후에는 기록을 종료한다.

관측 파일은 `outputs/browser-live-check-20261102/observations.jsonl`이다. 로컬 PC의 일회성 Windows 예약 작업이 10:20과 22:05에 로컬 기록과 기존 저장 파일의 수정 시각·크기를 읽어 `spot-report.json`, `night-report.json`으로 집계한다. 원격 접속이나 증권사 호출은 하지 않는다. 예약 작업은 이 PC가 켜져 있고 등록한 Windows 사용자로 로그인되어 있어야 실행된다.

집계는 검토용 근거다. 기록이 없으면 정상으로 판단하지 않는다. 동일한 데이터·캔들 화면이 유지되는 경우도 봉 종류, 휴장 여부, 선택한 갱신 주기에 따라 해석해야 한다. 미래 장중 검증을 지금 완료한 것으로 보고하지 않는다.
