# AI 역할 분담 지침 (Routing Rules)

당신은 작업을 수행할 때 반드시 다음 규칙에 따라 로컬 모델(Ollama)과 클라우드 모델(Codex Cloud)의 역할을 분담하여 실행 계획(Plan)을 세워야 합니다.

## 1. @ollama (로컬 오픈소스 AI) 담당 작업
- 구조가 단순한 보일러플레이트 코드 생성
- 단순 HTML/CSS 마크업 및 스타일링
- 변수명 추천, 함수 리팩토링, 주석(JSDoc 등) 및 문서 작성
- 단순 파일 읽기/쓰기 및 로그 분석 등의 1단계 에이전트 작업

## 2. @cloud (Codex Cloud / GPT-5) 담당 작업
- 복잡한 아키텍처 설계 및 대규모 리팩토링 기획
- 여러 파일이 얽혀 있는 복잡한 버그 추적 및 디버깅
- 보안이나 성능 최적화가 극도로 중요한 핵심 알고리즘 작성

## 3. 문서 검색 및 정보 조회 규칙
- **로컬 파일 검색:** 프로젝트 내부에 존재하는 코드, 텍스트, 설정 파일에서 내용을 찾을 때는 `@ollama`와 로컬 MCP 툴을 우선 사용하십시오.
- **외부/공식 문서 검색:** 외부 웹사이트, 최신 라이브러리 공식 API 문서, 웹 검색이 필요한 정보 조회는 `@cloud`를 사용해 수행하십시오.

## 4. 이미지 및 화면 캡처(Vision) 분석 규칙
- **단순 텍스트 추출 및 간단한 차트 분석:** 클라우드 토큰 절약이 필요할 때는 로컬 멀티모달 모델(`@ollama` 기반의 `qwen3-vl`)을 호출하여 처리하십시오.
- **복잡한 에러 스크린샷 디버깅 및 UI 구조 분석:** 이미지 속 정밀한 논리 추론과 코드 솔루션 제시가 필요한 복잡한 작업은 무조건 클라우드 모델(`@cloud`)을 사용하십시오.

## 실행 방식
- 에이전트가 `Plan 모드`로 실행될 때, 위 기준에 따라 하위 작업들을 쪼개고 로컬 툴(`ollama`)과 클라우드 기능을 적절히 배분하여 사용자에게 승인을 요청하십시오.
