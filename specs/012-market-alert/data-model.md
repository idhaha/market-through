# 시장경보 데이터

- 이벤트: UUID id, 시장(1/2), 종류(circuit/sidecar), 단계(1/2/3 또는 buy/sell), active, occurredAt/releasedAt/resumedAt, endedAt/endReason(장 종료 또는 단계 전환), 원본 상태 코드. 모든 시각은 서버 수신시각이며 실제 거래소 발생시각으로 표시하지 않는다.
- 상태: 한국 날짜, 당일 이벤트 최대 64개, 시장별 종료 여부, 사용자 식별자 SHA-256별 확인한 이벤트 id, 수신 진단 최대 200건.
- 런타임: 연결 상태, 수신 시작·마지막 수신·마지막 단절 시각. 서버 시작 전·연결 단절 구간의 완전한 이력 복구는 보장하지 않는다.
- 저장: Git 제외 `data/market-alerts/state.json`, 원자적 임시 파일 교체. 같은 날짜 재시작 시 이벤트와 확인 상태를 복구한다. 다음 한국 날짜에는 초기화한다.
- 동일 발동의 반복 수신은 기존 id를 유지한다. 상위 단계 발동은 별도 id를 만들어 이전 단계 확인과 무관하게 다시 점멸한다. 해제만 수신한 이벤트의 occurredAt은 null이다.
