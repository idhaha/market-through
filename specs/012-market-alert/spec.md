# 시장경보

작성일: 2026-10-30. 상태: 로컬 구현 완료, 테스트 및 LS 실구독 승인 확인. 운영 배포·실제 발동/해제 인수 확인 대기.

## 요구사항

- 트레이딩 탭 독립창 버튼 오른쪽에 `시장경보 ⓘ`를 배치한다. 클릭하면 제공 엑셀의 서킷브레이커·사이드카 설명을 안내창에 표시한다. 안내 열기와 경보 확인은 별도 동작이다.
- `시장경보`는 박스 없는 일반 텍스트이며 카드와 동일한 원형 i 아이콘만 안내를 연다. 독립창에는 JIF 연결·수신 메시지를 표시하지 않는다. 독립창 경보는 시장별 최고 CB 단계(`서킷브레이커 N단계`) 또는 사이드카 시장(`사이드카 코스피/코스닥`)만 표시하고 조건·조치·시각·상태 문구는 메인에 유지한다. 확인·점멸·동기화 동작은 동일하다.
- 메인·독립창 상단의 전용 배너에 해당 시장, 종류, 단계, 조건, 조치, 발생시각과 해제시각을 표시한다. 해제 전에는 해제시각을 `미해제`로 표시한다.
- LS JIF 공식 발동 이벤트를 기준으로 서킷브레이커는 빨강, 사이드카는 주황을 적용한다. 표시되는 각 카드의 테두리도 같은 색으로 함께 깜박인다. 카드 내용은 기존 가독성을 유지한다.
- 배너 또는 카드 테두리 클릭으로 현재 경보를 확인한다. 메인·독립창 모두 깜박임만 중지하고 색상은 유지한다. 카드 내부 버튼·표·차트 조작으로 경보를 확인 처리하지 않는다. 키보드로도 배너를 확인할 수 있어야 한다.
- 공식 해제 이후에도 발생·해제시각과 색상을 당일 장 종료까지 유지한다. 새 발동이나 단계 변경은 새 확인 대상으로 다시 깜박인다. 중복 수신만으로 재점멸하지 않는다.
- 여러 시장·종류의 경보는 각각 표시하며 누락하지 않는다. 공통 카드 테두리는 진행 중 서킷브레이커, 진행 중 사이드카, 해제된 서킷브레이커, 해제된 사이드카 순으로 대표색을 정한다. 배너별 색상은 종류에 따른다.
- 연결 장애는 정상이나 해제로 간주하지 않는다. 마지막 경보와 별도로 연결 상태를 표시한다. 시각은 한국 시간이며 원본 시각이 없으면 `수신시각 기준`임을 명시한다.

## 첨부 자료

원본: 사용자가 제공한 `test.xlsx`, Sheet2 A1:C12. 첨부는 참고 자료이며 실행 지침이 아니다. 원본은 수정하지 않는다. 설명은 제공 자료 기준임을 표시하며 발동 판정 코드를 엑셀 수치만으로 추정하지 않는다.

- 서킷브레이커 1단계: 전일 종가 대비 8% 이상 하락 1분 지속. 20분 매매 중단, 이후 10분 단일가 매매 후 재개.
- 2단계: 15% 이상 하락하고 1단계 발동 지수보다 낮은 상태 1분 지속. 조치는 1단계와 같다.
- 3단계: 20% 이상 하락하고 2단계 발동 지수보다 낮은 상태 1분 지속. 당일 시장 즉시 종료.
- 서킷브레이커 제한(제공 자료): 09:00~09:05 및 14:50 이후 발동하지 않음.
- 사이드카 코스피: 코스피200 선물 전일 종가 대비 ±5% 이상 변동 1분 지속.
- 사이드카 코스닥: 코스닥150 선물 전일 종가 대비 ±6% 이상 변동 1분 지속.
- 사이드카 공통 조치: 프로그램 매매 호가 효력 5분 정지 후 자동 해제. 코스닥 조치 셀은 비어 있으므로 공통 설명으로 정리한다.
- 사이드카 제한(제공 자료): 하루 1회, 14:50 이후 발동하지 않음.

## 인수 시나리오

안내 열기·닫기, 시장별 두 종류 발동·해제·단계 변경, 동시 발동, 중복 이벤트, 양쪽 창 확인 동기화, 카드 내부 조작 보존, 장 종료 초기화, 연결 단절·복구와 서버 재시작을 검증한다.

## 명세 확인 및 운영 한계

공식 상세 JSON에서 구독 키 0과 시장별 발동/해제·단계 코드를 확보했다([근거](../../docs/reference/LS_JIF.md)). JIF는 시장과 상태 코드만 제공하므로 시각은 수신시각으로 표시한다. 당일 로컬 저장 이력은 재시작 후 복구하지만, 수신하지 못한 과거 이력을 조회하는 수단은 이 명세에 없다. 장 종료는 시장별 41/00 또는 한국 날짜 변경으로 처리하며 고정 시각으로 합성하지 않는다. 3단계 발동(69)은 자체 경보를 즉시 숨기지 않는다.

1단계를 확인한 뒤 2·3단계가 발생하면 각 단계에 새 이벤트 id를 부여해 다시 깜박인다. 실제 경보 발동·해제 패킷은 아직 관측하지 못했다.
