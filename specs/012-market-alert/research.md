# 시장경보 조사

## 확인된 환경

- Node.js >=20, Express, ws, 빌드 없는 vanilla HTML/CSS/JS.
- 메인 트레이딩 제목 옆 `rankIndependentControls`에 Windows 독립창 버튼이 동적으로 생성된다. 경보 안내 버튼은 해당 플랫폼 분기로 숨기지 않는다.
- `ls-market-supply.js`는 서버 LS 토큰과 실시간 연결을 관리한다. 기존 수급 수집 시간 제한을 그대로 경보 수신에 적용할 수 있는지는 별도 확인이 필요하다.
- 독립창은 capability 인증과 서버 relay를 사용한다. 일반 로그인 전용 경보 API를 독립창에서 직접 호출하는 설계는 피한다.
- 현재 Git 브랜치는 `br_oracle`. 기존 미커밋 변경은 이번 작업에서 덮어쓰지 않는다. 기능 식별자 `012-market-alert`는 새 Git 브랜치를 만들었다는 뜻이 아니다.

## 결정

- 설명 데이터는 첨부에서 정리한 정적 데이터로 관리한다. 운영 서버에서 Excel 파싱 의존성을 추가하지 않는다.
- 실시간 발동은 공식 이벤트를 기준으로 한다. 지수 단순 등락률이나 타이머만으로 거래소 발동·해제를 단정하지 않는다.
- 이벤트 상태와 확인 상태는 분리한다. 동일 사용자 양쪽 화면에 같은 확인 결과를 제공하고 다른 사용자의 확인 상태와 섞지 않는다.
- 배경·테두리의 점멸만 변경하며 카드 내부 데이터·조작은 보존한다.

## 미해결 조사 — Phase 0 게이트

Ollama `qwen2.5:14b`에 첨부 발췌의 안내문 정리를 실제 위임했다. Codex 검토에서 초안의 `코스피 및 코스피200 선물` 표현은 현물·선물 동시 조건으로 오해할 수 있고, 상승·하락 양방향 설명 및 일부 전일 종가 기준 표현이 누락된 것을 확인했다. spec.md에는 원문 기준으로 바로잡아 기록했으며 초안을 그대로 채택하지 않았다. 호출 실패는 없었다. UI 코드 초안은 상태 계약 확정 후 위임한다.

LS 공식 서비스 목록 https://openapi.ls-sec.co.kr/apiservice 에 JIF가 존재함을 확인했다. 그러나 공식 상세 페이지를 통해 구독 키와 전체 상태 코드 설명을 확보하지 못했다. 검색으로 노출된 제3자 코드표는 구현 근거로 채택하지 않았다.

공식 JIF 명세에서 다음을 확인한 후 설계를 확정한다: 시장 구분, 구독 키, CB 단계와 조기종료 식별, 매수/매도 사이드카 발동·해제, 이벤트 시각, 재접속 시 현재 상태 조회 수단. 확인 전에는 Phase 1 계약과 구현을 완료한 것으로 보고하지 않는다.

## 2026-10-30 사용자 확인 및 장중 검증 경로

사용자는 알고 있는 공식 자료가 위 API 서비스 페이지뿐이며, 상세 정보가 없으면 장중 실시간 테스트로 확인하도록 지정했다. 추가 명세 제공을 사용자에게 요구하는 대신 공식 페이지 조사와 실측을 병행한다.

재조회한 공식 페이지에는 JIF 목록이 있으나 상세 영역에 `업스트림 연결 실패 / API 상세 정보를 가져오지 못했습니다`가 표시됐다. 이는 현재 조회 실패이며 명세 자체가 없다는 근거가 아니다. 페이지가 제공하는 DevCenter 가이드도 추가 조사 경로로 남긴다. 현재 도구의 in-app 브라우저는 사용 불가여서 해당 방식의 클릭 확인은 수행하지 못했다.

- 먼저 구독 형식과 ACK를 공식 자료 또는 실제 응답으로 확인한다. 인증 성공·구독 승인·실제 이벤트 수신은 별개로 기록한다.
- 장중 진단은 시세 구독만 수행하고 주문 API를 호출하지 않는다. 토큰·키를 제외한 JIF 응답 헤더의 TR/응답코드, 응답 body, 한국 시간 수신시각, 연결·재접속 정보를 제한된 크기로 기록한다.
- 기존 LS 연결의 구독을 방해하지 않도록 구독 추가 방식과 연결 제한을 확인한다. 진단 종료 후 구독 및 연결을 정리한다.
- 정상 장 상태와 시장 구분은 실제 장 상태와 대조한다. 정상 이벤트를 받았다는 이유만으로 CB·사이드카 코드까지 검증됐다고 보고하지 않는다.
- 경보 이벤트는 드물어 하루 관찰로 확인되지 않을 수 있다. 실제 발동·해제 관측 또는 공식 근거가 확보된 코드만 검증 완료로 표시한다. 미확인 코드는 진단에 남기고 임의 경보나 해제로 변환하지 않는다.
- JIF에 단계·발생시각이 없다면 추정하지 않는다. 단계는 `미확인`, 시각은 `수신시각 기준`으로 구분하며 정확한 단계 표시 요구는 미완료로 남긴다.
- 배너·테두리·확인 동기화는 모의 이벤트 재생으로 검증할 수 있으나 실제 JIF 의미 검증과 별도로 보고한다.
- 현재 장중 진단 코드 작성·실행이나 실제 구독은 수행하지 않았다. 실측은 이 세션이 장중에 실행될 때 수행하며 자동 예약이나 백그라운드 감시가 설정된 것은 아니다.
