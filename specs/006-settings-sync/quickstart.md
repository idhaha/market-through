# Quickstart: 설정 저장·동기화 검증

1. 탭 이름을 변경 → 페이지 새로고침 → 변경된 이름이 유지되는지 확인 (SC-001).
2. 서버를 잠시 중지한 상태에서 설정 변경 → 로컬에는 반영되고 경고가 표시되는지 확인.
3. 서버를 재시작하고 다른 브라우저에서 접속 → 마지막 저장된 서버 설정이 적용되는지 확인 (SC-002).
4. "전체 설정을 프로젝트 폴더에 백업하기" → 전체 상태를 담은 JSON 파일 하나가 localhost 서버 프로젝트 루트에 생성되는지 확인.
5. localhost와 Oracle 배포 호스트에서 단일 가져오기 버튼을 눌러 각 호스트의 JSON 파일이 스크롤 가능한 모달에 표시되는지 확인한다. 파일명 검색, 수정 시각·크기 표시, 자동 저장 파일 `user_settings_autosaved.json`을 확인한다.
6. 프로젝트 루트의 JSON 백업을 복원 → 확인 대화상자 통과 후 탭 구성이 동일한지 확인 (SC-004).
7. 가져오기 버튼의 풍선 도움말이 현재 서버 프로젝트 루트의 JSON에서 전체 설정을 복원한다는 점을 안내하는지 확인.

## 오프라인 폴백 검증 시 주의

브라우저 전체의 Network `Offline`은 앱 HTML/JS/CSS 요청까지 차단한다. 앱을 새로고침하면 앱 자체가 열리지 않으므로 설정 폴백 검증으로 볼 수 없다. 앱 파일 제공은 유지하면서 시작 시 `/api/settings` 요청만 실패시키는 환경에서 새로 로드하고, 요청 실패와 localStorage 탭 구성이 적용된 것을 함께 확인해야 한다. 앱이 이미 열린 상태에서 Offline을 켠 뒤 `전체조회`를 눌러 탭 레이아웃이 남는 것만으로는 초기 설정 로드의 폴백을 검증하지 못한다.
