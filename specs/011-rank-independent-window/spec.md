# Feature Specification: Rank 독립창

**Created**: 2026-10-11
**Status**: Implemented locally — Windows/WebView2 방식 확정, 운영 배포 및 실제 사용자 PC 인수 확인 대기
**Input**: Rank 거래대금 순위와 쏠림율차트를 하나의 독립창으로 함께 표시하고 원본을 유지한다. 사용자가 제시한 독립창 정책 전체를 기준으로 한다.

## User Scenarios & Testing

### US1 — 독립창 실행과 종료 (P1)

사용자는 Rank에서 독립창을 열어 거래대금 순위와 쏠림율차트를 함께 확인한다.

**Why this priority**: 원래 화면을 유지하며 같은 그룹을 별도 창에서 확인하는 핵심 기능이다.
**Independent Test**: 실행·중복 실행 시도·닫기·재실행 중 원본 및 조회 상태를 확인한다.

1. 독립창이 없는 상태에서 버튼을 클릭하면 독립창 하나를 생성하고 버튼을 비활성화한다.
2. 독립창 실행 전후 원래 Rank 표와 차트가 그대로 보이며 표시 대상 DOM을 이동하여 원본을 제거하지 않는다.
3. 독립창 닫기 또는 운영체제 닫기 후 버튼이 다시 활성화되고 기존 데이터/조회 상태를 유지하여 다시 열 수 있다.
4. 별도의 원래 화면 복귀 기능은 제공하지 않는다.

### US2 — 창 제어 (P1)

사용자는 독립창을 이동·크기 조절·최소화하고 항상 위를 전환한다.

**Why this priority**: 독립창을 다른 프로그램과 함께 사용하는 핵심 동작이다.
**Independent Test**: 다른 일반 운영체제 창과 함께 항상 위 전환, 최소화/복원, 이동/크기 조절을 확인한다.

1. 제목 표시줄은 [독립창]이며 오른쪽에 항상 위 체크박스·최소화·닫기 순서로 배치한다.
   제목 표시줄은 고정탭 기본 배경색(#e2e8f0)으로 맞추고 체크박스와 버튼은 세로 중앙에 맞춘다. 콘텐츠 상단의 갱신·조회는 오른쪽 끝에 모으고 해당 행의 위아래 여백을 최소화한다.
2. 제목 표시줄 드래그로 이동하며 가장자리로 크기를 조절하고 콘텐츠는 재배치한다. 표의 초기 글꼴·글자 크기·행 간격과 표시 배율을 메인 Rank와 맞춘다. 창 높이를 줄이면 셀 위아래 여백과 행 간격만 줄이고 글자 크기는 고정한다. 창을 키우면 Rank 기본 간격까지만 복원하고 그 이상 늘리지 않는다. 실제 목록 높이를 측정해 간격을 조절한다. 작은 창에서는 글자의 가독성과 스크롤을 유지한다.
3. 항상 위 설정은 즉시 적용되고 해제 시 일반 창 순서로 돌아온다. 메인 창에는 영향을 주지 않는다.
4. 최소화 버튼은 실제 운영체제 최소화를 수행하고 운영체제의 일반 복원 동작을 지원한다.

### US3 — 같은 상태 및 위치 복원 (P1)

사용자는 두 화면에서 같은 데이터·조건·선택·차트 설정을 확인하며 독립창 위치와 크기를 복원한다.

**Why this priority**: 중복 요청 및 불일치 없이 기존 조회 기능을 유지해야 한다.
**Independent Test**: 두 화면 중 한 화면에서 조건·선택·차트 설정 변경 후 다른 화면과 비교하고 창을 재실행한다.

1. 데이터 갱신과 조회 조건(시장·거래소·갱신 간격), 봉 종류·간격을 공유한다. 기본 선택 종목은 메인 페이지를 따른다. 독립창의 쏠림율차트 제목 바로 옆에 ‘쏠림율 차트 종목 동기화 해제’ 체크박스를 배치한다. 체크하면 두 화면은 각각 자유롭게 다른 종목을 선택한다. 체크 해제 시 메인 종목을 다시 따른다.
2. 줌·차트 구간 이동·스크롤은 화면별로 독립적으로 유지한다. 종목 동기화를 다시 연결하면 메인의 현재 선택 종목으로 돌아간다.
3. 독립창 열기/닫기 자체는 새 데이터 요청이나 같은 데이터 처리 연산을 중복 실행하지 않는다. 각 창의 표시를 위한 그리기는 허용한다.
4. 마지막 창 위치와 크기를 다시 실행할 때 복원한다.
5. 모니터가 제거되거나 저장 위치가 화면 밖이면 현재 사용 가능한 화면 안으로 조정한다.

### Edge Cases

- 창 실행 실패 시 버튼을 다시 활성화하고 실패 안내를 제공한다.
- 중복 클릭, 최소화 상태 및 운영체제 닫기 모두 단일 창 상태를 유지한다.
- 데이터 조회 실패 및 로딩 상태도 두 화면에서 일치하도록 한다.
- 다중 모니터·배율 변경 및 잘못된 저장 크기는 화면 범위 내에서 보정한다.
- 메인 화면 종료/새로고침 시 기존 연결을 끝내고 독립창을 닫는다. 연결 단절은 최대 120초 유예한다.
- 앱 미설치 및 브라우저 외부 앱 실행 취소 시 20초 연결 확인 후 안내와 설치 파일 자동 다운로드를 제공한다. 별도 설치 링크는 표시하지 않는다. 설치 여부를 브라우저에서 확정적으로 감지한다고 가정하지 않는다. 로그인/서버 연결 오류로는 설치 파일을 다운로드하지 않는다.

## Requirements

### Functional Requirements

- FR-001: 기능의 사용자 표시 명칭은 독립창으로 통일한다.
- FR-002: 거래대금 순위 및 쏠림율차트를 하나의 그룹으로 복제 표시하고 원본은 유지한다.
- FR-003: Rank 제목 바로 오른쪽에 독립창 버튼을 배치하고 상태 메시지는 버튼 오른쪽에 표시한다. 창이 없을 때 활성화, 실행 중 비활성화한다.
- FR-004: 단일 창만 허용하고 닫기 후 버튼 재활성화 및 조회 상태 유지 재실행을 지원한다.
- FR-005: [독립창] 제목 표시줄에 항상 위·최소화·닫기를 배치하고 제목줄 드래그 및 크기 조절을 지원한다.
- FR-006: 항상 위는 운영체제의 다른 일반 창에 대해 적용하며 즉시 전환하고 메인 창의 순서에는 영향을 주지 않는다.
- FR-007: 최소화는 운영체제 수준으로 수행하고 일반 복원을 지원한다.
- FR-008: 실행·종료는 표시 방식만 바꾸며 데이터 처리 로직을 변경하지 않는다.
- FR-009: 데이터·조회 조건·봉 종류/간격을 공유한다. 선택은 기본 공유 및 독립창 쏠림율 차트 종목 동기화 해제 예외를 제공한다. 줌·스크롤은 개별 상태이며 같은 조회는 메인 페이지에서 중복 요청을 합친다.
- FR-010: 창 위치·크기를 저장/복원하고 유효하지 않은 위치를 화면 안으로 보정한다.
- FR-011: 별도의 원래 Rank 복귀 기능을 제공하지 않는다.
- FR-012: Windows x64 독립창 앱은 WebView2를 사용한다. 서버에 브라우저 런타임을 포함하지 않으며, 없는 PC에서는 설치 프로그램이 Microsoft 서명을 확인한 공식 bootstrapper로 설치한다.
- FR-013: 독립창 버튼 하나로 실행하며, 앱 연결이 확인되지 않으면 안내와 함께 설치 파일을 자동 다운로드한다. https://azikanbal.duckdns.org 및 http://localhost:3000을 함께 허용한다. 다른 주소/포트는 거부한다.
- FR-014: 사용자 로그인 정보는 앱 실행 URI에 전달하지 않는다. 짧은 수명의 독립창 전용 토큰만 전달하며 메인 페이지의 세션/소유 키와 연결한다.
- FR-015: Windows 설치된 앱에 MarketThrough 독립창을 등록한다. 제거 시 앱 파일, 저장 상태, 사용자별 protocol 및 설치된 앱 등록을 함께 지우고 공유 WebView2 Runtime은 유지한다. 이전 앱을 덮어 설치하여 제거 기능을 등록할 수 있다.
- FR-016: 스마트폰 등 Windows 데스크톱 앱을 실행할 수 없는 기기에서는 독립창 버튼·상태 메시지를 표시하지 않고 실행/설치 다운로드 로직을 초기화하지 않는다. 화면 폭만으로 판단하지 않는다.
- FR-017: 독립창의 거래대금 상위·쏠림율차트 왼쪽 위에 각각 ▲ 접기/▼ 펼치기를 제공한다. 접어도 제목·버튼은 유지하며 메인의 표시나 조회 상태는 바꾸지 않는다. 접은 영역만큼 실제 창 크기를 줄이고 남은 콘텐츠의 크기는 유지한다. 펼치면 접기 전의 해당 영역 크기를 복원한다.
- FR-018: 쏠림율 차트를 분봉으로 전환할 때 기본 간격은 5분이다.
- FR-019: 캔들차트를 열 때마다 그 시점의 쏠림율차트 높이를 측정하고, 기존 높이를 유지하며 아래에 같은 높이의 캔들 영역을 추가한다. 실제 창 높이도 측정한 높이만큼 늘린다. 독립창 높이를 변경한 뒤 다시 펼칠 때는 변경된 높이를 사용한다. 닫으면 열기 전 창 높이를 복원한다. 화면 경계로 창 확장이 제한되면 차트 높이를 유지하고 스크롤로 내용을 표시한다.
- FR-020: 독립창에서 캔들 열기·닫기를 변경하면 메인이 해당 명령 ID를 반영한 상태를 확인할 때까지 이전 캔들 표시 상태로 덮어쓰지 않는다. 빠르게 반복 변경한 경우 가장 최근 명령을 기준으로 확인한다.

### Key Entities

- Rank 표시 그룹: 거래대금 순위와 선택 종목 쏠림율차트 및 관련 조회/표시 상태.
- 독립창 상태: 열림/닫힘/최소화, 항상 위 설정, 위치 및 크기.
- 공유 조회 상태: 최신 데이터, 조회 조건, 선택 및 차트 설정. 창 수와 무관하게 동일한 데이터 처리 주체를 사용한다.

## Success Criteria

- SC-001: 반복 실행 시도에서도 독립창은 최대 1개이며 원본 표·차트가 유지된다.
- SC-002: 단독 상태 대비 독립창 열기/닫기로 추가되는 자동 조회 요청은 0개이다.
- SC-003: 두 화면의 공유 조건 및 갱신 데이터가 일치하고, 쏠림율 차트 종목 동기화 해제 및 개별 줌·스크롤이 다른 화면을 변경하지 않는다.
- SC-004: 항상 위 전환·최소화/복원·닫기·이동·크기 변경이 운영체제 수준에서 요구대로 동작한다.
- SC-005: 다시 열 때 위치·크기를 복원하며 모니터 제거 후 화면 밖에 보이지 않는 창이 발생하지 않는다.

## Assumptions and Dependencies

Windows 데스크톱/WebView2 실행 환경을 사용자가 확정했다. Windows x64 및 .NET Framework 4.6.2 이상이 필요하다. WebView2가 없는 PC는 최초 설치 때 Microsoft 다운로드 연결이 필요하다. 메인 페이지는 연결 중 열려 있어야 한다. 서명되지 않은 자체 설치 파일의 Windows 안내가 발생할 수 있으며 코드 서명은 배포 운영 사항이다. 실제 다중 모니터, 다른 일반 앱과의 항상 위, 운영체제 최소화/복원, 신규 PC 런타임 자동 설치는 인수 확인 대상이다.
