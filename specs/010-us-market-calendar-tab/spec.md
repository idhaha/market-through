# Feature Specification: 자본동향 고정 탭

**Created**: 2026-10-10
**Status**: Implemented (로컬 기능 검증 완료, 최종 UI 및 운영 저장 검증 일부 대기)
**Input**: 증시캘린더 오른쪽에 자본동향 고정 탭을 추가하고 제목·URL 쌍의 추가, 열기, 편집, 저장, 새로저장, 삭제 및 순서 이동을 제공한다. 대화에서 확정된 화면 수정 사항까지 반영한다.

## User Scenarios & Testing

### User Story 1 - 항목 추가 및 열기 (Priority: P1)

사용자는 자본동향 탭에서 제목과 URL을 등록하고 원하는 사이트를 새 브라우저 탭으로 연다.

**Why this priority**: 자본동향 증시 관련 링크를 한곳에서 관리하고 바로 접근하는 기본 기능이다.
**Independent Test**: 빈 목록에서 제목·URL을 등록하고 각각 한 번 클릭해 같은 주소를 여는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 자본동향 탭 데이터가 없는 설정, **When** 화면을 초기화, **Then** 증시캘린더 바로 오른쪽에 자본동향 고정 탭을 생성하고 기준금리는 자본동향 오른쪽에 둔다.
2. **Given** 빈 목록 또는 기존 목록, **When** 상단 항목 추가 또는 표 아래 왼쪽 원형 + 버튼 클릭, **Then** 제목과 URL 입력 행을 표시한다.
3. **Given** 유효한 제목과 URL 입력, **When** 저장, **Then** 고유 ID가 있는 한 쌍으로 목록 끝에 추가하고 즉시 표시한다.
4. **Given** 저장된 항목, **When** 제목 또는 URL 셀을 한 번 클릭, **Then** 해당 URL을 새 브라우저 탭에서 연다.

### User Story 2 - 편집 및 원본 보존 복사 (Priority: P1)

사용자는 기존 항목을 수정하거나 별도의 항목으로 복사하고 필요하면 편집을 취소한다.

**Why this priority**: 제목과 URL의 연결 및 원본을 보존하면서 내용을 관리해야 한다.
**Independent Test**: 하나의 항목을 편집하여 저장·새로저장·ESC를 각각 수행하고 원본 및 목록을 비교한다.

**Acceptance Scenarios**:

1. **Given** 기존 항목, **When** 제목 또는 URL 셀을 여백 포함 더블클릭, **Then** URL을 열지 않고 같은 행에 두 입력창을 표시한다.
2. **Given** 편집 중인 기존 항목, **When** 저장, **Then** ID와 순서를 유지하면서 제목과 URL을 함께 덮어쓴다.
3. **Given** 편집 중인 기존 항목, **When** 새로저장, **Then** 원본을 변경하거나 삭제하지 않고 새 ID의 항목을 목록 끝에 추가한다.
4. **Given** 기존 항목과 제목 및 URL이 모두 동일한 입력, **When** 새로저장 또는 다른 항목을 해당 쌍으로 수정, **Then** 중복을 안내하고 저장하지 않는다.
5. **Given** 편집 중, **When** ESC 버튼 또는 입력창에서 Escape 키, **Then** 입력 내용을 취소하고 저장된 값으로 돌아간다.
6. **Given** 다른 행을 편집 중, **When** 다른 항목 편집 또는 추가 시작, **Then** 현재 입력을 취소할지 확인한다.

### User Story 3 - 삭제, 순서 이동 및 복원 (Priority: P2)

사용자는 불필요한 항목을 삭제하고 목록 순서를 조정하며 저장된 목록을 다시 불러온다.

**Why this priority**: 실수로 삭제하는 것을 막고 사용자가 정한 목록을 유지해야 한다.
**Independent Test**: 두 항목의 순서를 바꾸고 삭제 확인을 취소·승인한 뒤 설정을 복원한다.

**Acceptance Scenarios**:

1. **Given** 기존 항목 편집 중, **When** 삭제 버튼 클릭 후 확인 취소, **Then** 항목을 유지한다. 확인 승인 시 제목·URL 쌍 전체를 삭제한다.
2. **Given** 일반 상태의 두 항목, **When** ⠿ 핸들을 다른 행으로 드래그, **Then** 쌍을 유지하며 순서를 바꾸고 즉시 표시한다.
3. **Given** 저장·새로저장·삭제·순서 이동, **When** 작업 완료, **Then** 로컬 및 서버 설정 저장을 실행한다. 서버 실패는 상태 안내로 표시한다.
4. **Given** 저장된 전체 설정 또는 백업, **When** 불러오기, **Then** 항목의 ID·제목·URL·순서를 복원하고 자본동향 탭은 하나만 유지한다.

### Edge Cases

- 빈 제목·URL, 올바르지 않은 주소 및 HTTP/HTTPS 이외 주소는 저장하지 않고 안내한다. 입력 앞뒤 공백은 제거한다.
- 제목만 같거나 URL만 같으면 별도의 항목으로 저장할 수 있다.
- 긴 제목은 항목 열의 가로폭을 활용하고 필요 시 줄바꿈하며 긴 URL은 말줄임으로 열과 행 정렬을 유지한다. 좁은 화면에서는 가로 스크롤을 제공한다.
- 입력 중인 초안은 저장 전에 전체 설정에 포함하지 않는다. 설정 불러오기 시 초안은 폐기한다.
- 편집 중에는 드래그 순서 이동을 제한한다. 새 항목 입력 행에는 삭제 버튼이 없다.
- 오래된 설정에 자본동향 탭 정보가 없어도 빈 목록으로 사용할 수 있다.

## Requirements

### Functional Requirements

- **FR-001**: 자본동향은 증시캘린더 오른쪽의 고정 탭이며 동적 탭 삭제·정렬·초기화에서 보호한다. 고정 이름은 저장 및 복원 시 자본동향으로 정규화한다.
- **FR-002**: 하나의 행 왼쪽 항목 열에 제목과 그 아래 URL을 표시하고 오른쪽 설명 열에 설명을 표시한다. 제목·URL·설명은 하나의 ID로 연결한다.
- **FR-003**: 표는 항목·설명 두 제목만 표시한다. 오른쪽 작업 영역에는 필드 제목과 테두리를 표시하지 않고 편집 행에만 버튼을 둔다. 일반 상태에는 작업 영역을 확보하지 않고 설명 열을 확장한다. 편집모드에서만 작업 영역을 확보하며 ESC로 종료하면 설명 열을 다시 넓힌다. 설명 제목 글자는 일반 상태의 가운데 위치를 기준으로 편집 전후 동일한 가로 위치를 유지한다.
- **FR-004**: 흰색 기반 표에 행·열 구분선, 일관된 여백과 행 높이를 적용하고 제목행을 가운데 정렬한다. 긴 URL은 말줄임 처리하며 제목은 셀 너비를 활용하고 필요 시 줄바꿈한다. 항목 열보다 설명 열을 넓게 배치한다.
- **FR-005**: 상단 항목 추가와 표 아래 왼쪽의 원형 + 버튼은 동일한 추가 동작을 수행한다.
- **FR-006**: 제목·URL 셀의 단일 클릭은 새 탭 열기, 더블클릭은 편집으로 구분하며 더블클릭 시 새 탭을 열지 않는다.
- **FR-007**: 편집 시 제목과 URL을 함께 수정할 수 있고 기존 행의 버튼은 저장 → 새로저장 → ESC → 삭제 순서이다. 새로저장–ESC와 ESC–삭제 사이에는 동일한 추가 간격을 두고 글자색은 붉은색으로 표시한다.
- **FR-008**: 편집 입력창, 작업 버튼, 추가 버튼의 높이는 36px로 통일하고 아래 + 버튼은 36px 원형으로 표시한다.
- **FR-009**: 저장은 기존 ID의 값을 덮어쓰고 새로저장은 새로운 ID의 항목을 추가하며 원본을 보존한다.
- **FR-010**: 제목·URL 쌍 전체의 중복 추가 및 다른 항목과 동일한 쌍으로 수정하는 것을 막는다.
- **FR-011**: 삭제는 편집 중인 기존 항목에서만 제공하고 확인 승인 후 쌍 전체를 삭제한다.
- **FR-012**: ⠿ 드래그로 위아래 순서 이동을 제공하고 새 순서를 저장한다.
- **FR-013**: 변경 작업을 즉시 화면에 반영하고 기존 전체 설정 저장·불러오기·백업 복원에 포함한다. 초안은 저장된 항목과 분리한다.
- **FR-014**: 안내 문구는 `한 번 클릭: URL 열기 / 더블클릭: 편집 / ⠿ 드래그: 순서 이동`으로 표시한다.
- **FR-015**: 입력창의 Enter는 저장, Escape는 취소를 수행한다. 항목의 F2 편집은 키보드 보조 기능으로 유지하되 안내 문구에는 포함하지 않는다.

### Key Entities

- **자본동향 링크 항목**: 고유 ID, 제목, URL과 선택적 설명으로 구성되는 하나의 항목.
- **자본동향 링크 목록**: 항목의 표시 순서를 포함하는 저장된 목록.
- **편집 초안**: 원본 ID 또는 신규 상태, 입력 중인 제목·URL·설명. 명시적 저장 전에는 저장 목록에 반영하지 않는다.

## Success Criteria

### Measurable Outcomes

- **SC-001**: 항목 추가, 수정, 복사, 삭제 및 이동 후 목록과 순서가 사용자가 실행한 결과와 100% 일치한다.
- **SC-002**: 제목 및 URL 각각의 단일 클릭은 해당 주소를 열고 더블클릭은 편집만 수행한다.
- **SC-003**: 새로저장 후 원본 쌍과 ID가 유지되고 동일 쌍의 중복 항목은 0개 추가된다.
- **SC-004**: 일반·편집 상태 모두 저장 필드 제목과 작업 영역 테두리가 없으며 일반 상태의 설명 열이 편집 상태보다 넓다. 편집 시 요구된 버튼 순서, 동일 높이 및 가운데 정렬 제목행을 표시한다.
- **SC-005**: 설정 복원 후 항목의 ID·제목·URL·순서가 저장된 상태와 100% 일치하고 자본동향 고정 탭은 1개이다.

## Assumptions

- 기존 로그인 및 전체 설정 저장·복원 기능을 재사용한다. 자본동향 탭은 링크 목록 관리 기능이며 외부 일정 자동 수집은 범위에 포함하지 않는다.
- 초기 기본 링크는 지정하지 않았으므로 빈 목록으로 시작한다.
- 단일 클릭과 더블클릭 구분을 위한 짧은 열기 지연을 허용한다.
- 기존 기준금리 탭의 위치를 자본동향 오른쪽으로 이동하는 것은 본 기능의 확정된 화면 변경이다.

## 항목 설명 추가 — 2026-10-10

- FR-016: 왼쪽 항목 셀은 진한 제목 아래 작은 회색 URL을 표시하고 넓은 오른쪽 설명 셀에는 선택적 설명을 표시한다. 설명이 없는 기존 항목은 빈 설명으로 취급하고 기존 제목·URL을 유지한다.
- FR-017: 긴 설명은 기본 두 줄 또는 사용자가 입력한 줄 수 중 큰 값으로 접고 넘치는 경우에만 설명의 마지막 표시 줄 오른쪽 끝에 펼치기 버튼을 표시하고 별도 버튼 줄을 만들지 않는다. 설명 본문 더블클릭은 해당 항목 편집을 시작하고 설명 입력창에 포커스를 둔다. 펼치기/접기 버튼은 URL 열기 및 편집 동작을 실행하지 않는다. 접힌 상태와 펼친 상태 모두 저장한 Enter 줄바꿈을 유지한다. 접힌 상태도 직접 입력한 줄 수만큼 표시하며 긴 문장의 자동 줄바꿈으로 이를 넘는 내용은 펼치기로 확인한다. 필요에 따라 행 높이를 늘린다.
- FR-018: 편집모드의 항목 열에는 제목 및 그 아래 URL 입력창을, 설명 열에는 여러 줄 설명 입력창을 제공한다. 저장·새로저장 시 설명을 같은 ID의 제목·URL과 함께 관리하고 ESC는 설명 초안도 취소한다. 설명은 선택사항이며 중복 기준은 기존 제목·URL 쌍을 유지한다.
- FR-019: 제목/URL 입력 및 작업 버튼은 기존 36px 높이를 유지한다. 여러 줄 설명 입력창은 최소 72px로 제공하고 Enter는 줄바꿈, Ctrl/Command+Enter는 저장, Escape는 취소한다.

검증 시 기존 설명 없는 항목 편집, 설명 저장/취소, 새로저장 원본 보존 및 설명 복사, 두 줄 펼치기/접기 시 URL 미열기, 설정 복원을 확인한다.

## 열 너비 조절 — 2026-10-10

- FR-020: 항목·설명 제목행 사이 경계선을 마우스로 드래그하여 열 너비를 조절한다. 항목 열은 표 전체 너비의 15–65% 범위로 제한하고 기본값은 28%이다. 조절 완료 시 설정에 저장하고 설정 불러오기 및 재진입 시 복원한다. 편집 여부에 따른 설명 영역 확장과 제목 위치 보정은 유지한다. 경계선 포커스에서 좌우 화살표와 Home/End로도 조절한다.

## 탭 이름 변경 — 2026-10-10

기존 미국 탭의 표시 이름과 화면 제목을 자본동향으로 변경한다. 저장 및 복원 시 이름도 자본동향으로 정규화한다. 내부 tab_us ID와 contents.tab_us 저장 경로 및 명세 디렉터리 이름은 유지하여 기존 목록·설명·열 너비 설정을 그대로 사용한다.
