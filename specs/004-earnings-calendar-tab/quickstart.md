# Quickstart: 증시캘린더 탭 검증

1. 증시캘린더 탭 진입 → 10초 이내 당월 일정 표시 확인 (SC-001).
2. 일정 유형(경제지표/실적), 지역(국내/해외) 필터 각각 적용 → 1초 이내 목록 갱신 확인 (SC-002).
3. 이전/다음 월 버튼으로 월 전환 → 해당 월 일정 로드 확인.
4. 주별/월별 보기 전환 버튼 클릭 → 레이아웃이 올바르게 전환되는지 확인.
5. [새로고침] 클릭 → 접속 요청 시각이 갱신되고 load 이벤트 후 "캘린더 표시 중"으로 바뀌는지 확인 (SC-003).
6. `토스 캘린더 ↗` 버튼 → 새 창으로 `tossinvest.com/calendar`가 열리는지 확인.
## 다중 공급자 검증 범위

위 콘텐츠 검증은 Toss 지표/실적 일정에 적용한다. 세 공급자 모두 당일 재진입과 자동 갱신에서 기존 iframe을 유지하고, 새로고침 버튼은 선택한 iframe만 다시 접속한다. 상세 절차는 [007 quickstart](../007-multi-source-market-calendar/quickstart.md)를 따른다.
