# Feature Specification: 증시캘린더 탭 — 경제지표·실적 일정

**Feature Branch**: `004-earnings-calendar-tab`

**Created**: 2026-09-29

**Status**: Draft

**Input**: 기존 구현(브라운필드) 문서화 — 현재 구현과 이 Feature의 Spec Kit 산출물을 기준으로 정리

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 경제지표·실적 일정 조회 (Priority: P1)

사용자는 증시캘린더 탭에서 국내·해외 경제지표 발표 일정과 기업 실적 발표 일정을 주별 또는 월별로 확인할 수 있다.

**Why this priority**: 탭의 핵심 목적이며, 다른 부가기능 없이도 독립적으로 가치를 제공한다.

**Independent Test**: 탭을 열었을 때 당월 일정이 표시되고, 유형/지역 필터가 정상 동작하는지 확인해 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** 사용자가 증시캘린더 탭을 연 상태, **When** 페이지가 로드되면, **Then** 당월 경제지표·실적 일정이 표시된다.
2. **Given** 사용자가 일정 유형 필터(경제지표/실적)를 선택한 상태, **When** 필터가 적용되면, **Then** 해당 유형의 일정만 표시된다.
3. **Given** 사용자가 이전/다음 월 버튼을 클릭한 상태, **When** 월이 전환되면, **Then** 해당 월의 일정이 로드된다.

---

### User Story 2 - 주간 AI 요약 확인 (Priority: P2)

사용자는 이번 주 시장 이벤트에 대한 AI 요약을 카드 형태로 확인할 수 있다.

**Why this priority**: 부가 정보 제공 기능으로, 일정 조회(P1) 없이는 맥락이 없다.

**Independent Test**: 캘린더 화면에 주간 요약 카드가 표시되는지 확인해 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** 증시캘린더 탭이 로드된 상태, **When** 주간 요약 데이터 조회가 성공하면, **Then** 요약 제목과 내용이 카드로 표시된다.

---

### User Story 3 - 화면 새로고침 (Priority: P3)

사용자는 새로고침 버튼으로 캘린더 화면을 다시 불러올 수 있다.

**Why this priority**: 보조 기능으로, 기본 조회(P1)가 이미 자동으로 수행되므로 우선순위가 낮다.

**Independent Test**: 새로고침 버튼 클릭 시 상태 텍스트와 갱신 시각이 바뀌는지 확인해 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** 사용자가 새로고침 버튼을 클릭한 상태, **When** 약 100ms가 경과하면, **Then** 화면이 다시 로드되고 상태가 "새로고침 완료"로 표시된다.

### Edge Cases

- 토스증권 페이지 구조나 API 응답 형식이 변경되면 어떻게 되는가? → 요청 우회가 적용되지 않아 콘텐츠가 비어 있을 수 있다.
- 화면 캡처 모드 중 새로고침이 시도되면 어떻게 되는가? → 새로고침을 실행하지 않고 콘솔에만 기록한다.
- 허용되지 않은 외부 도메인으로 리소스 요청이 발생하면 어떻게 되는가? → 프록시는 `tossinvest.com`, `toss.im` 하위 호스트만 허용하며, 다른 도메인 요청은 차단된다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 국내·해외 경제지표 및 기업 실적 일정을 월간 및 주간 형식으로 표시해야 한다.
- **FR-002**: 사용자는 일정 유형(전체/경제지표/실적)과 지역(전체/국내/해외)으로 필터링할 수 있어야 한다.
- **FR-003**: 사용자는 주별 목록 보기와 월별 그리드 보기를 전환할 수 있어야 한다.
- **FR-004**: 시스템은 주간 AI 요약을 카드 형태로 제공해야 한다.
- **FR-005**: 사용자는 새로고침 버튼으로 캘린더 화면을 다시 로드할 수 있어야 한다.
- **FR-006**: 사용자는 원본 토스증권 캘린더 페이지를 새 창에서 직접 열 수 있어야 한다.
- **FR-007**: 시스템은 외부 리소스 프록시 요청을 신뢰할 수 있는 도메인으로만 제한해야 한다.
- **FR-008**: 화면 캡처 모드 중에는 새로고침을 실행하지 않아야 한다.
- **FR-009**: 새로고침 완료 상태 표시는 원격 데이터의 성공 여부를 검증하지 않고, 화면 재로드 완료 시점을 기준으로 한다.

### Key Entities

- **경제지표/실적 일정(Calendar Event)**: 날짜, 제목, 발표치, 예측치, 이전치를 가진다.
- **주간 AI 요약(Weekly Summary)**: 제목, 내용을 가진다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자는 탭 진입 후 10초 이내에 당월 일정을 확인할 수 있다.
- **SC-002**: 필터 적용 시 1초 이내에 목록이 갱신된다.
- **SC-003**: 새로고침 버튼 클릭 후 상태 텍스트가 항상 갱신 결과(완료 시각)로 정확히 반영된다.

## Assumptions

- 토스증권 웹 서비스의 페이지 구조와 API가 사양서 작성 시점과 동일하게 유지된다고 가정한다.
- 별도 로그인 없이 공개적으로 제공되는 일정 정보만 사용한다고 가정한다.
## Scope Update — 2026-10-05

이 문서의 필터·AI 요약·iframe 새로고침 및 캡처 모드 동작은 Toss 지표/실적 일정에 적용한다. 다중 공급자 전환과 Investing.com 각국 금리 일정의 PNG 캡처·당일 메모리 캐시·중앙 로딩 표시는 [007 기능 명세](../007-multi-source-market-calendar/spec.md)를 따른다. 각국 금리 일정은 일반 재진입 시 당일 성공 캐시를 재사용하고 새로고침 버튼은 다시 캡처하며 iframe 재로드 완료 메시지를 사용하지 않는다.
