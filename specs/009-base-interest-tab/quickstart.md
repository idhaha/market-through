# Quickstart: 기준금리 탭

1. 서버 재시작 후 로그인한다. 증시캘린더 바로 오른쪽에 기준금리 고정 탭이 하나만 생기는지 확인한다.
2. 탭을 선택한다. 중앙은행 12개 카드가 지정 순서대로 2열에 나타나고 제목은 약어 (중앙은행 명칭)인지 확인한다.
3. 조회 중 화면 로딩 중...과 진행 개수를 확인한다. API는 202로 즉시 응답하고 완료된 카드부터 이미지가 채워져야 한다.
4. 서로 다른 은행의 차트가 해당 코드와 일치하는지 원본 탭과 비교한다. 선택만 바뀌고 데이터가 바뀌지 않은 차트를 성공 처리하지 않아야 한다.
5. 다른 탭으로 이동 후 같은 날 돌아온다. 추가 API/외부 캡처 없이 기존 이미지를 사용해야 한다.
6. 우측 상단 새로고침을 누른다. force_refresh=true를 한 번 전달하고 새 캡처 후 조회 시각과 이미지가 갱신되어야 한다. 반복 클릭은 작업을 공유한다.
7. 일부 은행 실패를 유도한다. 해당 카드 오류를 표시하고 다른 은행은 계속 채워져야 한다. 새로고침으로 다시 조회할 수 있어야 한다.
8. 당일 성공 상태에서 강제 전체 실패를 유도한다. 기존 이미지와 실패 안내를 표시해야 한다.
9. 날짜 변경 후 다음 진입은 새 작업을 시작하는지 모의 날짜로 검증한다.
10. 기존 설정 또는 백업 복원 후에도 탭이 하나만 존재하고 동적 탭 초기화/삭제 대상에서 제외되는지 확인한다.
11. 서버에 PNG 파일이 생성되지 않는지, 완료/실패 후 캡처 브라우저가 종료되는지 확인한다. TE 및 중앙은행 테이블과 함께 사용해 브라우저 동시 1개인지 확인한다.

## 검증 기록

- 모의 상태 검증: 당일 캐시, 강제 새로고침, 중복 공유, 날짜 변경, 오류 및 이전 성공 보존 통과.
- headless 화면 검증: 고정 위치/중복 생성 방지/동적 초기화 보호, 12개 제목·순서·2열, 이미지 decode, 당일 요청 생략 및 버튼 force_refresh 전달 통과.
- 실제 사이트 캡처 및 운영 통합 검증 결과는 tasks.md에 기록한다.

- 실제 외부 캡처: FED/ECB/BOE/BOJ/BOK/RBA/BOC/SNB/RBI/BCB/CBR/PBOC 12개 전부 PNG 성공, 전체 약 47초(2026-10-06).
- 실제 캡처→API 상태 폴링→브라우저 카드 표시 통합 검증: 12개 PNG 650×350 모두 decode 완료, 당일 재진입 추가 캡처 없음. 임시 QA 화면 검토 통과.

## 응답 지연 검증

상태 요청을 타임아웃시킨 후 정상 응답으로 복구한다. 다시 확인 중 안내와 완료 이미지가 표시되는지 확인한다. force_refresh는 첫 요청에만 있고 재시도 요청에는 없어야 한다. 연속 실패가 재시도 3회를 넘으면 서버 응답 지연/연결 끊김 안내를 표시하며 기존 이미지가 있으면 유지한다. 모의 검증으로 위 재시도/강제 조회 1회/45초 제한/오류 문구/완료 캐시 재사용을 확인했다. Oracle 실제 환경 재검증은 별도로 필요하다.
