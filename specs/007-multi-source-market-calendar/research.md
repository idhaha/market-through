# Research / Decisions: 각국 금리 일정 이미지

**Date**: 2026-10-05

- 사용자가 확인한 Investing.com 중앙은행 페이지의 iframe 차단 때문에 기존 FED 일정 임베드를 테이블 PNG 방식으로 대체했다. source URL은 https://kr.investing.com/central-banks/ 이다.
- 사용자 첨부 test.js는 구현 참고 자료로 사용했다. 파일 저장·debug 캡처·기본 3초 대기를 그대로 복사하지 않고, 서버 이미지 저장 불필요 및 후속 1초 대기 요청을 우선 반영했다.
- 초기 실검증에서 테이블 식별에는 성공했으나 locator.screenshot이 외부 폰트를 기다리며 시간 초과했다. 폰트 요청 제외와 시스템 폰트 변경도 해결하지 못해 해당 시도는 최종 코드에서 제거했다.
- 최종 방식은 Playwright로 브라우저/DOM을 제어하고 CDP Page.captureScreenshot으로 테이블 영역을 PNG Buffer로 받는다. 실캡처 49,141바이트 및 PNG 시그니처를 확인했다. 이 검증 뒤 기본 대기를 3초에서 1초로 변경했다.
- 날짜별 캐시와 중복 Promise를 화면·서버 메모리에 두어 같은 날 메뉴 전환의 외부 재조회를 방지한다. 후속 요청에 따라 명시적 새로고침 버튼은 당일 캐시를 우회하여 재캡처하도록 변경했다. 디스크 영구 저장은 하지 않는다.
- 이미지 표시 폭은 최대 800px, 상단 여백은 30px인 현재 코드를 문서화했다. 캡처 해상도는 테이블 원본 영역 scale=1이고 화면 표시 크기와 별개다.
- 표시 지연에는 중앙 '화면 로딩 중...'을 사용하고 image.decode() 완료까지 유지한다. 지연 응답 브라우저 검증을 통과했다.
- 외부 접근 정책 변경이나 운영 서버 Chromium/자원 차이로 실서비스에서 추가 검증이 필요할 수 있다.
