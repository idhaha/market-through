# Feature Specification: 증시캘린더 다중 소스 탭

**Updated**: 2026-10-06
**Status**: Implemented — Oracle 서버 동작 사용자 확인 완료 (2026-10-06); 날짜 변경 로직은 로컬 모의 검증 완료
**Input**: 지표/실적 일정, 배당 일정, 각국 금리 일정을 각각 조회한 뒤 같은 날에는 재사용하고 새로고침 버튼으로 다시 조회한다.

## User Scenarios & Testing

### User Story 1 - 공급자 전환 (Priority: P1)

세 소탭 중 하나를 선택하면 해당 콘텐츠와 원본 사이트 링크를 표시한다. 최초 기본 선택은 지표/실적 일정이며 마지막 선택은 기존 설정 저장/복원 경로를 사용한다.

**Acceptance Scenarios**:

1. 지표/실적 일정은 Toss, 배당 일정은 SEIBro, 각국 금리 일정은 Investing.com 중앙은행 페이지를 표시한다.
2. 선택한 콘텐츠 하나만 보이고 다른 공급자의 열린 페이지는 유지한다.
3. 원본 사이트 버튼은 현재 공급자의 원본 페이지를 새 창에서 연다.

### User Story 2 - 당일 페이지 유지 (Priority: P1)

**Independent Test**: 세 공급자를 순서대로 열고 다른 소탭 및 메뉴를 다녀와도 추가 접속이 없는지 확인한다.

**Acceptance Scenarios**:

1. 각 공급자를 처음 선택할 때만 접속한다.
2. 한국시간 기준 같은 날에는 메뉴 이동, 소탭 전환 및 앱의 자동 갱신으로 다시 접속하지 않는다.
3. 새로고침 버튼은 선택한 공급자만 다시 접속한다.
4. 날짜가 바뀐 뒤 다음 진입 또는 앱 조회 시 해당 공급자에 다시 접속한다. 자정 자동 접속은 요구하지 않는다.

### User Story 3 - 각국 금리 일정 로딩 안내 (Priority: P2)

각국 금리 일정 접속 중 중앙에 `화면 로딩 중...`을 표시한다. 페이지 로드 이벤트 또는 20초 대기 후 안내를 해제한다. 빈 화면이면 원본 사이트를 확인할 수 있도록 안내한다.

## Edge Cases

- 서비스 페이지 자체 새로고침, 브라우저 재실행, 탭 DOM 재생성은 유지 상태를 초기화한다.
- 외부 페이지가 자체적으로 보내는 요청과 팝업은 앱의 당일 유지 정책에 포함하지 않는다.
- 외부 페이지 로드 이벤트만으로 HTTP 성공 및 콘텐츠 표시 성공을 판별할 수 없다.
- Investing.com 회원가입 팝업은 사용자가 직접 닫는다. 서비스에서 자동으로 닫는 기능은 제공하지 않는다.

## Requirements

- **FR-001**: 세 소탭 이름과 현재 공급자의 원본 링크를 유지한다.
- **FR-002**: 각 공급자의 열린 페이지를 독립적으로 보존하고 선택한 페이지 하나만 표시한다.
- **FR-003**: 같은 날 재진입과 자동 갱신은 추가 접속을 유발하지 않는다.
- **FR-004**: 명시적 새로고침은 현재 공급자만 다시 조회한다.
- **FR-005**: 날짜 변경 후 다음 조회에서 새 페이지를 요청한다.
- **FR-006**: 선택 상태는 저장하지만 열린 페이지와 조회 날짜는 설정 파일에 저장하지 않는다.
- **FR-007**: 각국 금리 일정은 전체 중앙은행 페이지를 표시하며 테이블 이미지 캡처를 요청하지 않는다.
- **FR-008**: 각국 금리 일정에 중앙 로딩 안내와 원본 사이트 확인 안내를 제공한다.
- **FR-009**: 탭 선택 상태와 키보드 포커스 및 로딩 상태 접근성을 제공한다.

## Success Criteria

- **SC-001**: 세 공급자를 반복 전환해도 공급자별 최초 접속은 1회이다.
- **SC-002**: 새로고침 버튼은 선택한 공급자의 접속 횟수만 1회 증가시킨다.
- **SC-003**: 날짜 변경 후 선택한 공급자는 1회 다시 접속한다.
- **SC-004**: 각국 금리 일정이 실제 서비스에서 표시된다(사용자 확인 완료).

## Assumptions

당일은 Asia/Seoul 기준이다. 외부 접근 정책에 따라 iframe이 차단될 수 있다. 이번 변경은 기준금리 12개 차트 캡처 기능을 변경하지 않는다.
